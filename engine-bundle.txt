# Shaders: the look, and how to switch it on

`src/engine/shaders.tsx` gives every film a real post-processing chain and a painted sky. It is **off by
default in the engine**; the narrated topic starters now switch it **on** in `film.tsx`. Existing films keep their choice.

```ts
post: { shaders: true },
```

or, to tune it:

```ts
post: { shaders: { bloom: 0.6, threshold: 1.25, vignette: 0.22, warmth: 0.45 } },
```

## What it does, in order

1. **Sky dome** (outdoor looks only). A shader on a sphere that follows the camera: vertical gradient, haze
   band at the horizon, a sun disc with a halo. Colours live in `LOOKS` in `Look.tsx` as `sky: { top, horizon,
   bottom, sun, haze }`. `overworld-day`, `overworld-sunset`, `overworld-night`, `lantern-night`,
   `overworld-storm`, `overworld-rain`, `town-day`, `street-day` and `lava-shore` all have one.
2. **Bloom** (`UnrealBloomPass`). Only genuinely over-bright things glow. The threshold is **above 1.0 on
   purpose**: a white caption is exactly 1.0 in linear light, so words stay crisp and the sun, torches and
   lanterns bloom. At 0.94 captions turned into fuzzy white blobs — do not go back there.
3. **Output** (`OutputPass`). **Required.** A composer renders into a render target, and three only applies
   tone mapping when it draws to the canvas; without this pass the film comes out linear and dark. This one
   mistake cost a whole render cycle: the frame looked like the lights had been turned off.
4. **Shafts** (custom shader): a radial scatter towards the sun on screen, so light streams across whatever
   sits in front of it. Off where there is no sky.
5. **Grade** (custom shader): highlight diffusion through the glass, a filmic shoulder, a lifted black point,
   saturation, warm midtones against cooled shadows, vignette, grain, and a pixel of lens fringing at the
   corners. Constant-tuned against the reference film, not by eye — see *Verified* below.

## What it is not

It does not replace the lighting presets. `Look.tsx` still decides where the light is and what colour it is;
shaders decide how the camera sees it. The reference film's richness is about 70% lighting and 30% grade.

## Verified, and by how much

Two scripts now decide this instead of a pair of eyes:

- `scripts/look-metrics.py` takes a picture apart into the things a shader does — warmth (mean R−B),
  saturation, how much light the frame holds, bloom, sky ramp, sky texture, vignette, soft edges, grain —
  and prints them next to the reference film's own numbers, measured with the same script.
- `scripts/shader-sim.py` pushes a real frame through the grade's maths and scores it against those
  numbers, so constants can be tuned in seconds instead of one Actions render at a time.

The reference (*His Dad Kept Punching The Same Tree For An HOUR..*, 32 frames) measures
warmth **+82**, saturation **77**, luma **17–198**, clipped **0.6 %**, glow **1.05x**, sky texture **7.2**,
soft edges **0.78**, grain **1.4**.

Measured on the scenery bench (`scenery-day`, before → after this pass of work):

| | before | after | reference |
|---|---|---|---|
| warmth (R−B) | +1.3 | **+54** | +82 |
| saturation | 48.5 | 46–68 | 77 |
| sky texture | 0.44 | 1.1–3.1 | 7.2 |
| blacks (p2) | 45 | 54 | 17 |
| soft edges | 0.88 | 0.89 | 0.78 |

Warmth and the black point moved most of the way to the reference. Sky texture is the gap that is
still open: the cloud layer is in, but it reads softer than the reference's. That is the next thing
to turn up — `cloudScale` and `clouds` on the outdoor looks in `Look.tsx`.

## Known gaps

- The sun disc is rarely in frame in our current camera language; when it is, it blooms.
- Shafts have no depth test: a roof cannot block one. Strength is a whisper by default for that reason.
- Cloud is a flat noise layer, not volume. It reads softer than the reference's sky.
- Sky is only visible outdoors. Interiors get bloom and grade, nothing else.

## The scenery bench

`src/scenery.tsx` is a shader test bench, registered as three compositions (`scenery-day`, `scenery-sunset`,
`scenery-night`) and deliberately kept out of `src/videos` so the film contract does not apply to it. One meadow,
one cottage, three oaks, three lenses: wide, medium, close.

Render stills without touching a film:

```
gh workflow run stills.yml -f composition=scenery-day -f frames=20 -f commit_review=true
```

Frames land in `review/scenery-day/`. Change the look in `src/scenery.tsx`, push, run again — that is the whole
loop for testing the grade.

# STYLE — Minecraft night cinema

This is the look. It is deliberately specific: deep-blue night, warm practicals, cold rim light, red carpet, green hospital corridor, pixel faces, volumetric glow. The goal is "a Zack D Films short happened inside a Minecraft world", not "a Minecraft render with a filter".

Read `AGENTS.md`, `docs/CAMERA-BIBLE.md` and `docs/SCENE-CONTRACT.md` first.

---

## 1. The visual thesis

- **Night, not black.** A night scene still has colour: navy walls, teal corridor, blue window light, warm sodium/fluorescent practicals. Pure black hides the set and the story.
- **One warm, one cold.** Every set balances a warm practical (orange, tungsten, sodium) against a cold moon/window/rim (blue, cyan, steel). The contrast is the mood.
- **Light pools, not flat fills.** Light lands somewhere: on the floor, the bed, the wall, the carpet. Use `LightPool` and `GodRay` to show the volume.
- **Silhouette first.** The audience should recognise the threat as a shape before they see a face. Rim/kicker light, back halo, fog.
- **Detail at three scales.** Big shape (architecture), medium props (bed, door, locker), micro detail (seams, vents, scuffs, cables, signs). A room with only the first two reads as a blockout.
- **Pixel faces only.** 8×8 maps, nearest filter. No realistic skin, no photo textures, no smooth gradients on the face.
- **The camera is inside the world.** No 2D cards, no HTML text, no screen-space effects. Text is a 3D sign.

## 3. The three-light rule

Every scene needs at least three jobs:

1. **Key** — the directional moon/window/sun. Casts the main shadow. One per film is enough.
2. **Practical** — the lamp, ceiling panel, monitor, sign or window the audience can see. It motivates the warm pool.
3. **Rim/kicker** — a cool edge behind the subject, so the silhouette separates from the wall.

Optional fourth: **bounce/fill** — a low, soft point light in front of the subject to reveal the face without flattening the room. Keep it 1–4 intensity and close.

### Light budget
- 1 directional key with shadows.
- 3–6 point lights for practicals/fills/rim.
- 1–2 `Glow` cards for lamps/eyes.
- `GodRay` cards for visible volume.
- `LightPool` cards for where light lands.
- `Dust` for the air.
- `FogCard` for depth or a dark end.

Shadows only on the key. More point lights = slower render, not better lighting.

### Exposure
`post.exposure` 1.05–1.2. If the window is a white rectangle, lower the window's `dim`/`emissiveIntensity`, not the exposure of the whole film. If the room is muddy, add a rim or a pool, not ambient.

---

## 4. Materials and textures

All textures are procedural canvas textures with `NearestFilter`:

- `pixelTex(color, repeat, { jitter })` — noisy block colour for walls/floors.
- `plankTex(color, repeat)` — floorboards.
- `carpetTex()` — red runner with a woven motif.
- `stripeTex(base, stripe, { count, horizontal })` — hospital gown.
- `posterTex(...)` / `Sign` — diegetic text.
- `windowTex()` — night window panes.

Use `Block` with `map` for large surfaces and `color` for trim. Do not use smooth `MeshStandardMaterial` on everything; the jitter is what makes it feel like a place. Keep `roughness` high (0.8–1) and `metalness` low except for metal props.

---

## 5. Detail hierarchy

### Big shape
Walls, floor, ceiling, corridor, doorway, window, bed, locker. These must be correct first. If the room reads as a box, no amount of dust will save it.

### Medium props
Bed with bedding, IV stand, monitor, nightstand, lamp, locker, chair, gurney, bin, cart, curtain, sign, clock. These tell the audience what the place is.

### Micro detail
Baseboards, wall seams, vents, door handles, hinges, thresholds, cables, scuffs, stains, notices, posters, ceiling beams, light diffusers. These are what separate "a room" from "a set".

**Rule:** every wall longer than 2m gets at least two pieces of micro detail. Every door gets a frame, a handle and a sign/threshold. Every bed gets a pillow, a sheet and a contact shadow.

### 6.7 Foreground occlusion

Put something at the edge of the lens:

```tsx
{/* a door frame in the near foreground */}
<Block position={[-2.1, 1.5, 4.2]} size={[0.12, 3, 0.18]} color="#0d241f" />

{/* a curtain / gurney / IV stand at the bottom of frame */}

```

Foreground occlusion creates parallax. The camera moves, the foreground slides, the background stays. That is 3D depth; no 2D blur can fake it.

## 7. Atmosphere placement

| Element | Put it | Opacity / intensity |
|---|---|---|
| `GodRay` | from a window/door into the room, along the light direction | 0.06–0.14 |
| `LightPool` | on the floor where the window/lamp lands | 0.12–0.3 |
| `Glow` | at a lamp, monitor, sign or eye | 0.2–0.5 (lamp), 0.7–0.9 (eye) |
| `Dust` | the volume the ray passes through | 0.2–0.35, 100–250 particles |
| `FogCard` | at a dark end or between camera and threat | 0.15–0.3 |
| `ContactShadow` | under every character/bed/prop | 0.4–0.6 |

Do not put a `GodRay` in the middle of a room with no source. Do not put `Glow` on every prop. Atmosphere should point to the light.

---

## 8. Composition

- **Three layers** in the hero frame: foreground (door frame, curtain, gurney), midground (kid, bed), background (window, hallway, figure).
- **Vertical leading lines**: door frames, wall seams, corridor edges, IV stand. Use them to pull the eye up/down the frame.
- **Subject in the upper third** for 9:16. Leave the lower third for the bed/floor/threat.
- **Off-axis**: 15–30° off flat-on. A cube flat-on is a square; a cube at an angle is a character.
- **Negative space**: the empty half of the bed, the dark doorway, the hall beyond. Negative space is where the audience puts the fear.
- **Frame inside a frame**: doorway, window, locker opening, curtain gap.
- **No naked centre**: if the subject is centred, give the frame a strong foreground or a threatening background.

---

## 9. Faces

- 8×8 pixel maps only. `neutral`, `worried`, `scared`, `surprised`, `happy`, `angry`, `sad`, `sleepy`, `blank`, `smug`, `crying`, `hollow`.
- Use `hollow` for the figure: hairline, near-black face, two 1px glowing eyes. Do not draw a realistic mouth on it.
- The kid's face is the reaction shot. Change `worried` → `scared` on the turn, not every frame.
- At close-up, the eye is a square. That is the style. Use a tight `Glow` sprite for the bloom, not a bigger eye.
- Add a `rim`/kicker and a back halo so the head does not merge with the wall.

---

## 10. Anti-patterns

| Anti-pattern | Why it fails | Fix |
|---|---|---|
| Flat ambient room | No shape, no mood, looks like a blockout | Key + practical + rim; shadows; pools |
| Pure black figure | Reads as a rectangle, not a person | Charcoal albedo, rim/kicker, halo, 3/4 angle |
| Overbright window | White rectangle, no depth | Lower `dim`, add falloff/pool, keep panes |
| Empty walls | The set feels unfinished | Seams, vents, signs, posters, scuffs |
| Box door/bed | The audience cannot identify it | Engine props + hardware + bedding |
| Centred flat-on camera | A cube looks like a square | 15–30° off-axis, foreground, low/high angle |
| Cut every second | No tension, no geography | 3–5 shots, one fly-through |
| 2D text overlay | Breaks the 3D illusion | 3D `Sign` in the set |
| Realistic face | Breaks the Minecraft style | 8×8 map, nearest filter |
| Too many glows | Foggy, gamey, slow | One glow per source; pool where it lands |

---

## 11. Performance

- Keep `Dust` under ~250 particles per volume.
- Keep point lights to 4–7. Shadows only on the key.
- Reuse materials/textures (the engine caches canvas textures).
- Avoid transparent full-screen planes; `FogCard` is a small card, not a full-screen quad.
- No `@react-three/postprocessing`; it produced black frames under software WebGL.
- Test at 1080×1920, 30fps. If a still takes minutes on the user's machine, stop and ask before rendering.

---

## 12. The quality bar

A frame is ready when:

- the silhouette reads without colour;
- the light tells you where it comes from;
- the set tells you what the place is;
- the face tells you what the character feels;
- the composition tells you where to look;
- and there is one detail you did not need but are glad is there.

If it looks like a blockout with a blue filter, it is not ready.

---

## Daylight, and real blocks

The recipes above are for dark interiors. An outdoor Minecraft film is the opposite problem: too much light and
nothing to look at. Three things carry it.

**Blocks, not colours.** `<Vox kind="cobble" size={[12, 5, 1]} />` is a wall of sixty cobblestone blocks, each a
16×16 face, one per metre. Kinds: `grass dirt path cobble mossy stone stoneBrick planks darkPlanks log leaves bricks
wool sand hay basalt obsidian magma lava`. `tint` recolours one (dyed wool, a painted roof); `side` gives grass its dirt.
Build a house from five or six big `Vox`, never from unit cubes. A flat-coloured `Block` next to a `Vox` looks unfinished.

**One colour world per act.** `overworld-day` (blue sky, hard warm sun), `overworld-night` (blue, with torches doing
the warm work), `lava-shore` (the ground is the lamp), `overworld-storm` (purple sky, low warm light). Set `look` on
the shot. A viewer should know where in the story they are from one frame.

**Fill for faces at night.** A face turned to the lens at night is lit by nothing. Put a soft light on the camera's
side of the set (the bedroom in `in-this-town-monster-egg` has one) or give someone a `<Torch light>` to hold.

import { TAU, clamp01, lerp, pulse, wobble } from "./math";
import type { Vec3 } from "./math";

/**
 * Procedural animation clips. No rig files, no mixamo, no bones — just the
 * classic Minecraft limb pivots, driven by maths so every frame is deterministic.
 *
 * Two flavours of clip:
 *
 *   TIME-BASED   `getPose(name, t)`      — idles, reactions, one-shots.
 *   DISTANCE     `gaitPose(name, dist)`  — walking/running. The phase comes from
 *                                          how far the character has travelled,
 *                                          so the feet always match the ground
 *                                          speed and nobody shuffles in place.
 *
 * Angles are radians. `bodyY` is metres. The character faces +Z.
 */
export type Pose = {
  bodyY: number;
  bodyPitch: number;
  bodyRoll: number;
  bodyYaw: number;
  torso: Vec3;
  head: Vec3;
  armR: Vec3;
  armL: Vec3;
  legR: Vec3;
  legL: Vec3;
  kneeR: Vec3;
  kneeL: Vec3;
};

export type AnimName =
  | "idle"
  | "talk"
  | "walk"
  | "run"
  | "creep"
  | "stagger"
  | "jump"
  | "fall"
  | "sit"
  | "sitDown"

  | "scared"

  | "guard";

/** Walking clips whose phase is driven by ground distance, not the clock. */
export type GaitName = "walk" | "run" | "creep" | "stagger";

/** Metres of ground one full stride cycle covers. Tune so the feet never skate. */
export const STRIDE: Record<GaitName, number> = {
  walk: 1.42,
  run: 2.1,
  creep: 1.12,
  stagger: 1.55,
};

const zero = (): Pose => ({
  bodyY: 0,
  bodyPitch: 0,
  bodyRoll: 0,
  bodyYaw: 0,
  torso: [0, 0, 0],
  head: [0, 0, 0],
  armR: [0, 0, 0],
  armL: [0, 0, 0],
  legR: [0, 0, 0],
  legL: [0, 0, 0],
  kneeR: [0, 0, 0],
  kneeL: [0, 0, 0],
});

const lerpVec = (a: Vec3, b: Vec3, t: number): Vec3 => [
  lerp(a[0], b[0], t),
  lerp(a[1], b[1], t),
  lerp(a[2], b[2], t),
];

/** Linear blend between two poses. Use for walk→idle, sit→stand, panic→collapse. */
export function blendPose(a: Pose, b: Pose, t: number): Pose {
  const k = clamp01(t);
  return {
    bodyY: lerp(a.bodyY, b.bodyY, k),
    bodyPitch: lerp(a.bodyPitch, b.bodyPitch, k),
    bodyRoll: lerp(a.bodyRoll, b.bodyRoll, k),
    bodyYaw: lerp(a.bodyYaw, b.bodyYaw, k),
    torso: lerpVec(a.torso, b.torso, k),
    head: lerpVec(a.head, b.head, k),
    armR: lerpVec(a.armR, b.armR, k),
    armL: lerpVec(a.armL, b.armL, k),
    legR: lerpVec(a.legR, b.legR, k),
    legL: lerpVec(a.legL, b.legL, k),
    kneeR: lerpVec(a.kneeR, b.kneeR, k),
    kneeL: lerpVec(a.kneeL, b.kneeL, k),
  };
}

/**
 * Distance-driven gait. `distance` is metres travelled along the path.
 * Feet, arms and pelvis all come from the same phase, so the cycle is
 * physically consistent: stop moving and the legs stop mid-stride.
 */
export function gaitPose(name: GaitName, distance: number): Pose {
  const p = zero();
  const stride = STRIDE[name];
  const cycle = (Math.max(0, distance) / stride) * TAU;
  const s = Math.sin(cycle);
  const c = Math.cos(cycle);

  if (name === "walk") {
    p.bodyY = Math.abs(s) * 0.035 - 0.008;
    p.bodyRoll = c * 0.028;
    p.legR = [s * 0.74, 0, 0];
    p.legL = [-s * 0.74, 0, 0];
    p.kneeR = [Math.max(0, s) * 0.78 + 0.03, 0, 0];
    p.kneeL = [Math.max(0, -s) * 0.78 + 0.03, 0, 0];
    p.armR = [-s * 0.66, 0, 0.05];
    p.armL = [s * 0.66, 0, -0.05];
    p.torso = [0.045, s * 0.05, 0];
    p.head = [-0.03, -s * 0.04, 0];
    return p;
  }

  if (name === "run") {
    p.bodyY = Math.abs(s) * 0.075 - 0.02;
    p.bodyPitch = -0.22;
    p.bodyRoll = c * 0.045;
    p.legR = [s * 1.05, 0, 0];
    p.legL = [-s * 1.05, 0, 0];
    p.kneeR = [Math.max(0, s) * 1.2 + 0.18, 0, 0];
    p.kneeL = [Math.max(0, -s) * 1.2 + 0.18, 0, 0];
    p.armR = [-s * 1.1 - 0.4, 0, 0.12];
    p.armL = [s * 1.1 - 0.4, 0, -0.12];
    p.torso = [-0.12, s * 0.08, 0];
    p.head = [0.1, -s * 0.05, 0];
    return p;
  }

  if (name === "creep") {
    // Hesitant, flat-footed. Short steps, held breath, hands slightly out.
    p.bodyY = Math.abs(s) * 0.02 - 0.014;
    p.bodyPitch = 0.07;
    p.bodyRoll = c * 0.016;
    p.legR = [s * 0.52, 0, 0.01];
    p.legL = [-s * 0.52, 0, -0.01];
    p.kneeR = [Math.max(0, s) * 0.48 + 0.14, 0, 0];
    p.kneeL = [Math.max(0, -s) * 0.48 + 0.14, 0, 0];
    p.armR = [-0.34 + s * 0.18, 0, 0.14];
    p.armL = [-0.34 - s * 0.18, 0, -0.14];
    p.torso = [0.05, s * 0.03, 0];
    p.head = [0.07, -s * 0.09, 0.03];
    return p;
  }

  // stagger — drunk, injured, or something wearing a person's shape wrong.
  p.bodyY = Math.abs(s) * 0.05 - 0.01;
  p.bodyPitch = 0.1;
  p.bodyRoll = c * 0.075;
  p.legR = [s * 0.82, 0, 0.06];
  p.legL = [-s * 0.82, 0, -0.06];
  p.kneeR = [Math.max(0, s) * 0.85 + 0.08, 0, 0];
  p.kneeL = [Math.max(0, -s) * 0.85 + 0.08, 0, 0];
  p.armR = [-0.5 - s * 0.55, 0, 0.3];
  p.armL = [-0.5 + s * 0.55, 0, -0.3];
  p.torso = [0.09, s * 0.12, 0];
  p.head = [0.06, -s * 0.14, 0.09];
  return p;
}

/** Time-based clips. Reactions, one-shots and anything that does not travel. */
export function getPose(name: AnimName, t: number): Pose {
  const p = zero();
  const time = Math.max(0, t);

  switch (name) {
    case "idle": {
      p.bodyY = Math.sin(time * 1.4) * 0.012;
      p.head = [0.04 + Math.sin(time * 0.7) * 0.03, Math.sin(time * 0.45) * 0.12, 0];
      p.armR = [Math.sin(time * 1.4) * 0.04, 0, 0.03];
      p.armL = [-Math.sin(time * 1.4) * 0.04, 0, -0.03];
      p.torso = [0, Math.sin(time * 0.45) * 0.02, 0];
      return p;
    }

    case "lookAround": {
      p.bodyY = Math.sin(time * 1.2) * 0.01;
      p.head = [Math.sin(time * 0.8) * 0.05, Math.sin(time * 0.55) * 0.55, 0];
      p.armR = [0.02, 0, 0.03];
      p.armL = [0.02, 0, -0.03];
      return p;
    }

    case "talk": {
      p.bodyY = Math.sin(time * 1.5) * 0.012;
      p.head = [Math.sin(time * 3.2) * 0.045, Math.sin(time * 0.9) * 0.14, 0];
      p.torso = [0, Math.sin(time * 0.9) * 0.04, 0];
      p.armR = [-0.35 + Math.sin(time * 2.4) * 0.22, 0, 0.18];
      p.armL = [-0.12 + Math.sin(time * 1.7) * 0.1, 0, -0.1];
      return p;
    }

    // Legacy time-driven walk/run. Prefer gaitPose() so the feet match the ground.
    case "walk": {
      const s = Math.sin(time * TAU * 1.75);
      const c = Math.cos(time * TAU * 1.75);
      p.bodyY = Math.abs(s) * 0.035 - 0.01;
      p.bodyRoll = c * 0.025;
      p.legR = [s * 0.72, 0, 0];
      p.legL = [-s * 0.72, 0, 0];
      p.kneeR = [Math.max(0, s) * 0.7, 0, 0];
      p.kneeL = [Math.max(0, -s) * 0.7, 0, 0];
      p.armR = [-s * 0.62, 0, 0.05];
      p.armL = [s * 0.62, 0, -0.05];
      p.torso = [0.04, s * 0.06, 0];
      p.head = [-0.02, -s * 0.05, 0];
      return p;
    }

    case "run": {
      const s = Math.sin(time * TAU * 2.6);
      const c = Math.cos(time * TAU * 2.6);
      p.bodyY = Math.abs(s) * 0.07 - 0.02;
      p.bodyPitch = -0.22;
      p.bodyRoll = c * 0.04;
      p.legR = [s * 1.05, 0, 0];
      p.legL = [-s * 1.05, 0, 0];
      p.kneeR = [Math.max(0, s) * 1.15 + 0.15, 0, 0];
      p.kneeL = [Math.max(0, -s) * 1.15 + 0.15, 0, 0];
      p.armR = [-s * 1.1 - 0.35, 0, 0.12];
      p.armL = [s * 1.1 - 0.35, 0, -0.12];
      p.torso = [-0.12, s * 0.09, 0];
      p.head = [0.12, -s * 0.06, 0];
      return p;
    }

    case "creep": {
      // Time fallback for creep, for callers that have no distance.
      return gaitPose("creep", time * 0.95);
    }

    case "stagger": {
      return gaitPose("stagger", time * 1.35);
    }

    case "sitDown": {
      const k = clamp01(time / 0.85);
      const e = k * k * (3 - 2 * k);
      p.bodyY = lerp(0, -0.125, e);
      p.legR = [lerp(0, -Math.PI / 2, e), 0, lerp(0, 0.04, e)];
      p.legL = [lerp(0, -Math.PI / 2, e), 0, lerp(0, -0.04, e)];
      p.kneeR = [lerp(0, Math.PI / 2, e), 0, 0];
      p.kneeL = [lerp(0, Math.PI / 2, e), 0, 0];
      p.armR = [lerp(0, -0.32, e), 0, lerp(0, 0.08, e)];
      p.armL = [lerp(0, -0.32, e), 0, lerp(0, -0.08, e)];
      p.bodyPitch = lerp(0, -0.04, e);
      p.head = [lerp(0, 0.06, e), 0, 0];
      return p;
    }

    case "standUp": {
      const k = clamp01(time / 0.72);
      const e = k * k * (3 - 2 * k);
      p.bodyY = lerp(-0.125, 0, e);
      p.legR = [lerp(-Math.PI / 2, 0, e), 0, lerp(0.04, 0, e)];
      p.legL = [lerp(-Math.PI / 2, 0, e), 0, lerp(-0.04, 0, e)];
      p.kneeR = [lerp(Math.PI / 2, 0.06, e), 0, 0];
      p.kneeL = [lerp(Math.PI / 2, 0.06, e), 0, 0];
      p.armR = [lerp(-0.32, 0, e), 0, lerp(0.08, 0.03, e)];
      p.armL = [lerp(-0.32, 0, e), 0, lerp(-0.08, -0.03, e)];
      p.bodyPitch = lerp(-0.04, 0.02, e);
      p.head = [lerp(0.06, 0.04, e), 0, 0];
      return p;
    }

    case "cower": {
      const shiver = wobble(time * 7.3, 2) * 0.035;
      p.bodyY = -0.3 + Math.abs(Math.sin(time * 3.1)) * 0.012;
      p.bodyPitch = 0.3;
      p.bodyRoll = shiver;
      p.legR = [-0.62, 0, 0.1];
      p.legL = [-0.62, 0, -0.1];
      p.kneeR = [1.25, 0, 0];
      p.kneeL = [1.25, 0, 0];
      p.armR = [-2.5 + shiver, 0, 0.35];
      p.armL = [-2.5 - shiver, 0, -0.35];
      p.head = [0.34, 0, 0];
      return p;
    }

    case "peek": {
      const lean = Math.sin(time * 1.1) * 0.5 + 0.5;
      p.bodyPitch = -0.12 * lean;
      p.bodyY = -0.06 * lean;
      p.head = [0.1 - 0.14 * lean, 0.1 * Math.sin(time * 0.7), 0];
      p.armR = [-0.5 - 0.2 * lean, 0, 0.1];
      p.armL = [-0.2, 0, -0.1];
      p.legR = [-0.14, 0, 0.05];
      p.legL = [-0.14, 0, -0.05];
      p.kneeR = [0.22, 0, 0];
      p.kneeL = [0.22, 0, 0];
      return p;
    }

    case "press": {
      const k = clamp01(time / 0.5);
      const press = Math.sin(k * Math.PI);
      p.armR = [-1.35 - press * 0.3, 0, 0.1];
      p.armL = [-0.1, 0, -0.06];
      p.bodyPitch = -0.06 - press * 0.04;
      p.head = [-0.14, -0.08, 0];
      p.bodyY = -press * 0.01;
      return p;
    }

    case "reachUp": {
      p.armR = [-2.6 + Math.sin(time * 1.3) * 0.08, 0, 0.2];
      p.armL = [-0.2, 0, -0.08];
      p.bodyPitch = -0.14;
      p.head = [-0.28, 0, 0];
      p.bodyY = Math.sin(time * 1.3) * 0.008;
      return p;
    }

    case "jump": {
      const cycle = 1.05;
      const q = time % cycle;
      const crouch = pulse(q, 0, 0.24);
      const air = pulse(q, 0.26, 0.78);
      const land = pulse(q, 0.78, 1.0);
      p.bodyY = crouch * -0.09 + air * 0.52 - land * 0.06;
      p.bodyPitch = -0.06 + crouch * 0.12;
      p.legR = [air * -0.55 - crouch * 0.35, 0, air * 0.08];
      p.legL = [air * -0.55 - crouch * 0.35, 0, air * -0.08];
      p.kneeR = [air * 0.85 + crouch * 1.1, 0, 0];
      p.kneeL = [air * 0.85 + crouch * 1.1, 0, 0];
      p.armR = [air * -2.2 - crouch * 0.15, 0, air * 0.35];
      p.armL = [air * -2.2 - crouch * 0.15, 0, air * -0.35];
      p.head = [air * 0.12, 0, 0];
      return p;
    }

    case "fall": {
      p.bodyPitch = 0.12 + Math.sin(time * 3.1) * 0.05;
      p.bodyRoll = Math.sin(time * 2.3) * 0.09;
      p.armR = [-2.5 + Math.sin(time * 5.1) * 0.12, 0, 0.45];
      p.armL = [-2.5 - Math.sin(time * 5.1) * 0.12, 0, -0.45];
      p.legR = [-0.2, 0, 0.18];
      p.legL = [-0.35, 0, -0.18];
      p.head = [-0.12, 0, 0];
      return p;
    }

    case "sit": {
      // Hips drop to bed height, thighs horizontal, feet hanging.
      p.bodyY = -0.125 + Math.sin(time * 1.6) * 0.008;
      p.legR = [-Math.PI / 2, 0, 0.04];
      p.legL = [-Math.PI / 2, 0, -0.04];
      p.kneeR = [Math.PI / 2, 0, 0];
      p.kneeL = [Math.PI / 2, 0, 0];
      p.armR = [-0.32, 0, 0.08];
      p.armL = [-0.32, 0, -0.08];
      p.bodyPitch = -0.04;
      p.head = [0.06 + Math.sin(time * 1.1) * 0.02, Math.sin(time * 0.4) * 0.08, 0];
      return p;
    }

    case "lie": {
      p.bodyPitch = -Math.PI / 2;
      p.bodyY = -0.125;
      p.armR = [0, 0, 0.18];
      p.armL = [0, 0, -0.18];
      p.legR = [0, 0, 0.03];
      p.legL = [0, 0, -0.03];
      p.head = [0, 0, 0.08];
      return p;
    }

    case "sleep": {
      p.bodyPitch = -Math.PI / 2;
      p.bodyY = -0.125 + Math.sin(time * 1.1) * 0.006;
      p.armR = [0, 0, 0.22];
      p.armL = [0, 0, -0.22];
      p.legR = [0, 0, 0.02];
      p.legL = [0, 0, -0.02];
      p.head = [0, -0.25, 0.1];
      return p;
    }

    case "scared": {
      const shiver = wobble(time * 9, 3) * 0.03;
      p.bodyY = -0.05 + shiver * 0.3;
      p.bodyPitch = 0.1;
      p.bodyRoll = shiver;
      p.armR = [-1.5 + shiver, 0, 0.55];
      p.armL = [-1.5 - shiver, 0, -0.55];
      p.legR = [-0.12, 0, 0.08];
      p.legL = [-0.12, 0, -0.08];
      p.head = [0.1, wobble(time * 7, 1) * 0.12, 0];
      return p;
    }

    case "crouch": {
      p.bodyY = -0.26;
      p.bodyPitch = 0.22;
      p.legR = [-0.55, 0, 0.08];
      p.legL = [-0.55, 0, -0.08];
      p.kneeR = [1.25, 0, 0];
      p.kneeL = [1.25, 0, 0];
      p.armR = [0.25, 0, 0.12];
      p.armL = [0.25, 0, -0.12];
      p.head = [-0.08, 0, 0];
      return p;
    }

    case "reach": {
      p.bodyPitch = -0.05;
      p.armR = [-1.55, 0, 0.18];
      p.armL = [-0.15, 0, -0.08];
      p.head = [-0.12, -0.1, 0];
      p.bodyY = Math.sin(time * 1.4) * 0.01;
      return p;
    }

import type { Vec3 } from './math';

/** World-space occupied boxes, in metres. Use the SAME position/size for the set mesh.
 * A walker's position is its feet. Contact is legal; penetration is not. These are
 * conservative blocking volumes, not a physics simulation of swinging limbs.
 */
export type SetSolid = { name: string; position: Vec3; size: Vec3 };
export type BodyClearance = { radius: number; height: number };
const EPS = 1e-6;
const finitePoint = (p: Vec3) => p.length === 3 && p.every(Number.isFinite);

// Intersect the entire segment with the box expanded by the actor's footprint
// and height. Checking only marks (or sampling a few frames) misses thin walls.
function crosses(a: Vec3, b: Vec3, box: SetSolid, body: BodyClearance) {
  let enter = 0, leave = 1;
  for (let k = 0; k < 3; k++) {
    const low = box.position[k] - box.size[k] / 2 - (k === 1 ? body.height : body.radius) + EPS;
    const high = box.position[k] + box.size[k] / 2 + (k === 1 ? 0 : body.radius) - EPS;
    const delta = b[k] - a[k];
    if (Math.abs(delta) < EPS) {
      if (a[k] <= low || a[k] >= high) return false;
    } else {
      const t0 = (low - a[k]) / delta, t1 = (high - a[k]) / delta;
      enter = Math.max(enter, Math.min(t0, t1)); leave = Math.min(leave, Math.max(t0, t1));
      if (leave < enter) return false;
    }
  }
  return true;
}

/** Rehearse once, at construction. Then sample exactly this path (not a spline
 * that cuts the corner). The returned distance drives MinecraftAvatar's gait.
 * One mark is allowed: check a stationary actor too. Pass only this zone's solids.
 */
export function blockedRoute(label: string, marks: Vec3[], solids: SetSolid[], body: BodyClearance) {
  if (!marks.length || marks.some(p => !finitePoint(p)) || !Number.isFinite(body.height) || body.height <= 0 ||
      !Number.isFinite(body.radius) || body.radius < 0) throw Error(`${label}: invalid marks or body clearance`);
  for (const s of solids) {
    if (!finitePoint(s.position) || !finitePoint(s.size) || s.size.some(v => v <= 0)) throw Error(`${label}: invalid solid ${s.name}`);
  }
  const fixed = marks.map(p => [...p] as Vec3); // a caller moving its input must not change the checked path
  const legs = fixed.map((a, i) => {
    const b = fixed[i + 1] ?? a;
    for (const s of solids) if (crosses(a, b, s, body)) {
      throw Error(`${label}: mark ${i + 1}${i + 1 < marks.length ? ` → ${i + 2}` : ''} crosses ${s.name}. Move the mark or route around it.`);
    }
    return { a, b, length: Math.hypot(b[0] - a[0], b[1] - a[1], b[2] - a[2]) };
  }).filter(l => l.length > EPS);
  const length = legs.reduce((n, l) => n + l.length, 0);
  function sample(distance: number): Vec3 {
    let left = distance;
    for (const leg of legs) {
      if (left <= leg.length || leg === legs[legs.length - 1]) {
        const { a, b } = leg, k = Math.min(1, left / leg.length);
        return [a[0] + (b[0] - a[0]) * k, a[1] + (b[1] - a[1]) * k, a[2] + (b[2] - a[2]) * k];
      }
      left -= leg.length;
    }
    return [...fixed[0]];
  }
  return (progress: number) => {
    if (!Number.isFinite(progress)) throw Error(`${label}: non-finite route progress`);
    const animDistance = Math.min(1, Math.max(0, progress)) * length;
    // Soften the facing, NOT the path: a spline here would cut the checked corner.
    const before = sample(Math.max(0, animDistance - .15));
    const after = sample(Math.min(length, animDistance + .15));
    return { position: sample(animDistance), rotationY: Math.atan2(after[0] - before[0], after[2] - before[2]), animDistance };
  };
}

/**
 * MINECRAFT BLOCKS.
 *
 * <Vox> is a box of any size whose faces are tiled one block per metre, so a
 * 12 × 5 × 1 wall reads as 60 cobblestone blocks, not one stretched picture.
 * Build towns out of a few big Vox, never out of thousands of unit cubes.
 */

const GEOMETRY = new Map<string, THREE.BoxGeometry>();

function voxGeometry(size: Vec3, tile: number): THREE.BoxGeometry {
  const key = `${size[0]}|${size[1]}|${size[2]}|${tile}`;
  const hit = GEOMETRY.get(key);
  if (hit) return hit;
  const [w, h, d] = size;
  const geometry = new THREE.BoxGeometry(w, h, d);
  const uv = geometry.attributes.uv as THREE.BufferAttribute;
  // BoxGeometry faces, in order: +x, -x, +y, -y, +z, -z. Four vertices each.
  const spans: Array<[number, number]> = [[d, h], [d, h], [w, d], [w, d], [w, h], [w, h]];
  for (let face = 0; face < 6; face++) {
    for (let v = 0; v < 4; v++) {
      const i = face * 4 + v;
      uv.setXY(i, (uv.getX(i) * spans[face][0]) / tile, (uv.getY(i) * spans[face][1]) / tile);
    }
  }
  uv.needsUpdate = true;
  GEOMETRY.set(key, geometry);
  return geometry;
}

import { useEffect } from "react";
import { useFrame, useThree } from "@react-three/fiber";
import { useCurrentFrame, useVideoConfig } from "remotion";
import * as THREE from "three";
import { clamp01, easings, focalMmToFov, wobble } from "./math";
import type { Vec3 } from "./math";
import type { Shot } from "./types";

/**
 * Drives the render camera from a list of SHOTS.
 *
 * One `<Camera>` per scene. Each shot owns a time window, so hard cuts inside a
 * scene are explicit and reviewable. Between scenes the camera simply keeps its
 * last transform, which is how a continuous fly-through can carry across a cut.
 */

function pathCurve(points: Vec3[]): THREE.CatmullRomCurve3 {
  return new THREE.CatmullRomCurve3(
    points.map((p) => new THREE.Vector3(p[0], p[1], p[2])),
    false,
    "centripetal",
    0.5,
  );
}

function samplePath(
  path: Vec3[] | undefined,
  a: Vec3,
  b: Vec3 | undefined,
  e: number,
  arc: number,
): THREE.Vector3 {
  if (path && path.length >= 2) {
    return pathCurve(path).getPointAt(clamp01(e));
  }
  const end = b ?? a;
  const p = new THREE.Vector3(a[0], a[1], a[2]).lerp(new THREE.Vector3(end[0], end[1], end[2]), e);
  if (arc !== 0) {
    const dir = new THREE.Vector3(end[0] - a[0], 0, end[2] - a[2]);
    if (dir.lengthSq() > 1e-6) {
      const side = new THREE.Vector3().crossVectors(dir, new THREE.Vector3(0, 1, 0)).normalize();
      p.addScaledVector(side, Math.sin(Math.PI * e) * arc);
    }
  }
  return p;
}

export function pickShot(shots: Shot[], t: number): Shot {
  let active = shots[0];
  for (const shot of shots) {
    if (shot.at <= t + 1e-6) active = shot;
  }
  return active;
}

export const Camera: React.FC<{ shots: Shot[]; duration: number; sceneId?: string }> = ({
  shots,
  duration,
  sceneId,
}) => {
  const camera = useThree((s) => s.camera) as THREE.PerspectiveCamera;
  const frame = useCurrentFrame();
  const { fps } = useVideoConfig();
  const t = frame / fps;

  const shot = pickShot(shots, t);
  const p = clamp01((t - shot.at) / Math.max(shot.dur, 1e-6));
  const e = easings[shot.ease ?? "inOutCubic"](p);

  // Camera position
  const position = samplePath(shot.path, shot.from, shot.to, e, shot.arc ?? 0);

  // Where it looks
  const target = samplePath(shot.targetPath, shot.target, shot.targetTo, e, 0);
  target.y += shot.aim ?? 0;

  // Handheld instability: deterministic, subtle, applied to both ends of the look ray.
  if (shot.shake && shot.shake > 0) {
    const amp = shot.shake;
    position.x += wobble(t * 7.1, 1) * amp;
    position.y += wobble(t * 6.3, 2) * amp * 0.7;
    position.z += wobble(t * 5.7, 3) * amp;
    target.x += wobble(t * 7.9, 4) * amp * 1.2;
    target.y += wobble(t * 8.3, 5) * amp * 0.9;
    target.z += wobble(t * 6.9, 6) * amp * 1.2;
  }

  // Operator breathing: slow, low amplitude, always present when enabled.
  if (shot.handheld && shot.handheld > 0) {
    const amp = shot.handheld;
    position.x += wobble(t * 0.53, 11) * amp;
    position.y += wobble(t * 0.41, 12) * amp * 0.8;
    position.z += wobble(t * 0.47, 13) * amp * 0.6;
    target.x += wobble(t * 0.61, 14) * amp * 1.4;
    target.y += wobble(t * 0.57, 15) * amp;
    target.z += wobble(t * 0.44, 16) * amp * 1.4;
  }

  // Timed impacts: a decaying burst of shake, for a footstep or a door slam.
  if (shot.impacts && shot.impacts.length > 0) {
    for (const impact of shot.impacts) {
      const dur = impact.dur ?? 0.35;
      const local = t - impact.at;
      if (local < 0 || local > dur) continue;
      const decay = Math.pow(1 - local / dur, 2);
      const amp = impact.amp * decay;
      position.x += wobble(local * 26 + impact.at * 7, 21) * amp;
      position.y += wobble(local * 23 + impact.at * 5, 22) * amp * 0.9;
      target.x += wobble(local * 31 + impact.at * 3, 23) * amp * 1.3;
      target.y += wobble(local * 29 + impact.at * 9, 24) * amp;
    }
  }

  // Lens: millimetres win over degrees, so a shot can say "35mm" and keep the
  // framing legible to a human. See focalMmToFov() for the sensor assumption.
  const baseFov = shot.focalLength != null ? focalMmToFov(shot.focalLength) : (shot.fov ?? 38);
  const endFov =
    shot.focalLength != null
      ? focalMmToFov(shot.focalLengthTo ?? shot.focalLength)
      : (shot.fovTo ?? baseFov);
  const fov = baseFov + (endFov - baseFov) * e;
  const roll = (shot.roll ?? 0) + ((shot.rollTo ?? shot.roll ?? 0) - (shot.roll ?? 0)) * e;

  useFrame(() => {
    camera.position.copy(position);
    camera.up.set(0, 1, 0);
    camera.lookAt(target);
    if (roll) camera.rotateZ(roll);
    if (Math.abs(camera.fov - fov) > 1e-4) {
      camera.fov = fov;
      camera.updateProjectionMatrix();
    }
  }, -1); // Update before sky, billboards and post, including on a non-sequential frame seek.

  useEffect(() => {
    const last = shots[shots.length - 1];
    const end = last.at + last.dur;
    if (end < duration - 0.05) {
      console.warn(
        `[${sceneId ?? "scene"}] camera plan ends at ${end.toFixed(2)}s but the scene is ${duration.toFixed(2)}s. ` +
          `The last shot will hold. Add a shot or shorten the scene.`,
      );
    }
    for (let i = 1; i < shots.length; i++) {
      if (shots[i].at < shots[i - 1].at + shots[i - 1].dur - 0.001) {
        console.warn(`[${sceneId ?? "scene"}] shot ${i} overlaps shot ${i - 1}.`);
      }
    }
  }, [shots, duration, sceneId]);

  return null;
};

import type { Vec3 } from "./math";
import type { Shot } from "./types";

/**
 * Camera recipes: a shot described the way a director says it.
 *
 *   ...cam.push({ on: [0, 1.5, 0], dist: 3, to: 2.3, yaw: 20 })
 *
 * Every recipe MOVES. That is the point: a fast-cut film dies on a locked-off
 * frame, and a hand-typed from/to pair is where still frames and typos come from.
 *
 * Angles are degrees.
 *   yaw   — where the camera stands around the subject. 0 = on the +Z side,
 *           looking back at it (the front of an actor whose rotationY is 0).
 *           90 = on the +X side. 180 = behind.
 *   pitch — how high. 0 = level with the look point, 30 = above looking down,
 *           -20 = below looking up (a hero angle).
 *
 * Spread the result into a shot. Add `note`, and `stage` in a story scene.
 */

type Move = Pick<Shot, "from" | "to" | "path" | "target" | "targetTo" | "fov" | "fovTo" | "roll" | "rollTo" | "ease">;

const RAD = Math.PI / 180;

/** A point `dist` metres from `on`, at the given yaw/pitch. */
export function around(on: Vec3, dist: number, yaw = 0, pitch = 0): Vec3 {
  const y = yaw * RAD;
  const p = pitch * RAD;
  return [
    round(on[0] + dist * Math.sin(y) * Math.cos(p)),
    round(on[1] + dist * Math.sin(p)),
    round(on[2] + dist * Math.cos(y) * Math.cos(p)),
  ];
}

const round = (n: number) => Math.round(n * 1000) / 1000;
const lerp = (a: number, b: number, k: number) => a + (b - a) * k;

type Framing = {
  /** The point the lens looks at: usually a chest (y≈1.25), a face (y≈1.55) or a prop. */
  on: Vec3;
  /** Metres from the look point when the shot opens. */
  dist: number;
  yaw?: number;
  pitch?: number;
  /** Vertical field of view. Default 40. Close-ups 30–36, wides 48–58. */
  fov?: number;
};

export const cam = {
  /** Dolly in (to < dist) or pull out (to > dist) along the lens axis. The workhorse. */
  push(o: Framing & { to: number; onTo?: Vec3; fovTo?: number }): Move {
    return {
      from: around(o.on, o.dist, o.yaw, o.pitch),
      to: around(o.onTo ?? o.on, o.to, o.yaw, o.pitch),
      target: o.on,
      ...(o.onTo ? { targetTo: o.onTo } : {}),
      fov: o.fov ?? 40,
      ...(o.fovTo ? { fovTo: o.fovTo } : {}),
      ease: "inOutSine",
    };
  },

  /** Swing around the subject. yawTo/pitchTo/distTo are where the arc ends. */
  orbit(o: Framing & { yawTo: number; pitchTo?: number; distTo?: number; onTo?: Vec3 }): Move {
    const steps = 5;
    const path: Vec3[] = [];
    for (let i = 0; i < steps; i++) {
      const k = i / (steps - 1);
      const on: Vec3 = o.onTo
        ? [lerp(o.on[0], o.onTo[0], k), lerp(o.on[1], o.onTo[1], k), lerp(o.on[2], o.onTo[2], k)]
        : o.on;
      path.push(
        around(
          on,
          lerp(o.dist, o.distTo ?? o.dist, k),
          lerp(o.yaw ?? 0, o.yawTo, k),
          lerp(o.pitch ?? 0, o.pitchTo ?? o.pitch ?? 0, k),
        ),
      );
    }
    return {
      from: path[0],
      path,
      target: o.on,
      ...(o.onTo ? { targetTo: o.onTo } : {}),
      fov: o.fov ?? 40,
      ease: "inOutSine",
    };
  },

  /** The camera stays put and the look sweeps from one thing to another. */
  pan(o: { from: Vec3; on: Vec3; onTo: Vec3; fov?: number; fovTo?: number }): Move {
    return {
      from: o.from,
      target: o.on,
      targetTo: o.onTo,
      fov: o.fov ?? 40,
      ...(o.fovTo ? { fovTo: o.fovTo } : {}),
      ease: "inOutSine",
    };
  },

  /** Camera and look point slide together by `by`: tracking beside a walker, sliding along a row. */
  truck(o: Framing & { by: Vec3 }): Move {
    const from = around(o.on, o.dist, o.yaw, o.pitch);
    return {
      from,
      to: [round(from[0] + o.by[0]), round(from[1] + o.by[1]), round(from[2] + o.by[2])],
      target: o.on,
      targetTo: [round(o.on[0] + o.by[0]), round(o.on[1] + o.by[1]), round(o.on[2] + o.by[2])],
      fov: o.fov ?? 40,
      ease: "inOutSine",
    };
  },

  /** Straight down on a thing on the floor. `spin` (degrees) turns the frame as it rises or sinks. */
  top(o: { on: Vec3; height: number; to: number; spin?: [number, number]; fov?: number }): Move {
    // A hair off vertical so the camera always knows which way is up.
    const at = (h: number): Vec3 => [o.on[0], round(o.on[1] + h), round(o.on[2] + h * 0.02)];
    return {
      from: at(o.height),
      to: at(o.to),
      target: o.on,
      fov: o.fov ?? 40,
      ...(o.spin ? { roll: o.spin[0] * RAD, rollTo: o.spin[1] * RAD } : {}),
      ease: "inOutSine",
    };
  },
};

===== FILE: src/engine/caption-beat.ts =====
import type { CaptionWord } from './types';

const POP = 0.22;

/** Reserve width for the whole accent. Capping the result each frame would
 * pin a long word at the maximum width, erasing its pop. */
export function captionPixel(width: number, textureWidth: number, size: number, onBeat: boolean) {
  return Math.min(width / 86 * size, width * .88 / (textureWidth * (onBeat ? 1 + POP : 1)));
}

/** At normal speech speed this is round(onset * fps). If two short words land on
 * one frame, give the second its own frame; recover on the next natural gap. */
export function beatFrames(words: readonly CaptionWord[], fps: number): number[] {
  let last = -1;
  return words.map(word => (last = Math.max(last + 1, Math.round(word.s * fps))));
}

/** Sample the *recording's* clock, never a CSS transition or the previous rendered frame.
 * Round onsets to the nearest output frame unless two words compete for it.
 * A short release bridges consecutive words, but never writes over a dramatic silence.
 */
export function captionBeat(words: readonly CaptionWord[], starts: number[], frame: number, fps: number) {
  let lo = 0, hi = words.length;
  while (lo < hi) {
    const mid = (lo + hi) >>> 1;
    if (starts[mid] <= frame) lo = mid + 1;
    else hi = mid;
  }
  const word = words[lo - 1];
  if (!word || frame >= Math.max(starts[lo - 1] + 1, Math.ceil((word.e + 0.09) * fps))) return null;
  const age = (frame - starts[lo - 1]) / fps;
  const attack = Math.max(0, 1 - age / 0.13) ** 2;
  return { word, scale: 1 + POP * attack, lift: 0.008 * attack };
}

import { useMemo } from "react";
import { useFrame } from "@react-three/fiber";
import { useCurrentFrame, useVideoConfig } from "remotion";
import * as THREE from "three";
import { clamp01 } from "./math";
import { beatFrames, captionBeat, captionPixel } from "./caption-beat";
import { wordTexture } from "./pixelfont";
import type { CaptionSettings, CaptionWord } from "./types";

/**
 * One word on screen at a time, cut to the voice.
 *
 * It is a quad drawn in screen space INSIDE the 3D canvas (same WebGL context,
 * no HTML layer), so it survives every renderer the film does. The letters come
 * from a bit table (pixelfont.ts), so no font has to be installed anywhere.
 *
 * Films do not mount this. Pass `captions` to defineFilm.
 */

const VERT = /* glsl */ `
  uniform vec4 rect; // centre x, centre y, half width, half height — all in clip space
  varying vec2 vUv;
  void main() {
    vUv = uv;
    gl_Position = vec4(rect.xy + position.xy * rect.zw, 0.0, 1.0);
  }
`;

const FRAG = /* glsl */ `
  uniform sampler2D map;
  varying vec2 vUv;
  void main() {
    vec4 c = texture2D(map, vUv);
    if (c.a < 0.5) discard;
    gl_FragColor = vec4(c.rgb, 1.0);
  }
`;

/** What a word looks like on screen: no punctuation, one case. */
export function captionText(word: string, letterCase: "upper" | "lower" = "upper"): string {
  const clean = word.replace(/[^A-Za-z0-9'\-]/g, "").replace(/^['-]+|['-]+$/g, "");
  return letterCase === "upper" ? clean.toUpperCase() : clean.toLowerCase();
}

/** The word being spoken at `t`, or null in a pause. */
export function activeWord(words: CaptionWord[], t: number): CaptionWord | null {
  let lo = 0;
  let hi = words.length - 1;
  let hit = -1;
  while (lo <= hi) {
    const mid = (lo + hi) >> 1;
    if (words[mid].s <= t) {
      hit = mid;
      lo = mid + 1;
    } else hi = mid - 1;
  }
  if (hit < 0) return null;
  const word = words[hit];
  const next = words[hit + 1];
  // Hold the word until the next one starts, but not across a real pause.
  const holdUntil = next ? Math.min(next.s, word.e + 0.45) : word.e + 0.45;
  return t < holdUntil ? word : null;
}

export const Captions: React.FC<CaptionSettings> = ({ words, y = 0.72, size = 1, letterCase = "upper", motion }) => {
  const frame = useCurrentFrame();
  const { fps, width, height } = useVideoConfig();
  const t = frame / fps;

  const material = useMemo(
    () =>
      new THREE.ShaderMaterial({
        uniforms: { map: { value: null }, rect: { value: new THREE.Vector4(0, 0, 0, 0) } },
        vertexShader: VERT,
        fragmentShader: FRAG,
        transparent: true,
        depthTest: false,
        depthWrite: false,
        fog: false,
        toneMapped: false,
      }),
    [],
  );

  const starts = useMemo(() => motion === "on-beat" ? beatFrames(words, fps) : null, [motion, words, fps]);
  const beat = starts ? captionBeat(words, starts, frame, fps) : null;
  const word = motion === "on-beat" ? beat?.word : activeWord(words, t);
  const text = word ? captionText(word.w, letterCase) : "";

  let rect: [number, number, number, number] | null = null;
  let tex: THREE.DataTexture | null = null;
  if (word && text.length > 0) {
    tex = wordTexture(text);
    const texW = (tex.image as { width: number }).width;
    const texH = (tex.image as { height: number }).height;
    // One font pixel is 1/86 of the frame width; long words shrink to fit 88%.
    const px = captionPixel(width, texW, size, !!beat);
    // A two-frame pop on the cut to each word. It is what makes the eye follow.
    const pop = beat?.scale ?? (1 + 0.2 * Math.pow(1 - clamp01((t - word.s) / 0.1), 2));
    const halfW = ((texW * px) / width) * pop;
    const halfH = ((texH * px) / height) * pop;
    rect = [0, 1 - 2 * (y - (beat?.lift ?? 0)), halfW, halfH];
  }

  useFrame(() => {
    if (rect && tex) {
      material.uniforms.map.value = tex;
      (material.uniforms.rect.value as THREE.Vector4).set(rect[0], rect[1], rect[2], rect[3]);
    }
  });

  return (
    <mesh frustumCulled={false} renderOrder={9999} visible={rect !== null} material={material}>
      <planeGeometry args={[2, 2]} />
    </mesh>
  );
};

  const frame = useCurrentFrame();

const FilmView: React.FC<{ config: FilmConfig }> = ({ config }) => {
  const { fps, width, height } = useVideoConfig();
  const frame = useCurrentFrame();

  // Lay the scenes out in FRAMES, not seconds. Rounding each scene's start and
  // length independently can leave a one-frame gap or overlap between scenes
  // (scene N ends on frame 101, scene N+1 starts on frame 102). Accumulating
  // frames keeps every scene butt-joined to the previous one.
  const sequences = useMemo(() => {
    let cursorFrames = 0;
    return config.scenes.map((scene, index) => {
      const from = cursorFrames;
      const durationInFrames = Math.max(1, Math.round(scene.duration * fps));
      cursorFrames += durationInFrames;
      return { scene, index, from, durationInFrames };
    });

  // sit outside the scene <Sequence>s, so they get it from here.

    const seq =
      sequences.find((s) => frame >= s.from && frame < s.from + s.durationInFrames) ?? sequences[sequences.length - 1];
    const sceneT = (frame - seq.from) / fps;
    const shot = pickShot(seq.scene.shots, sceneT);
    return {
      shot,
      scene: seq.scene,
      sceneIndex: seq.index,
      shotIndex: seq.scene.shots.indexOf(shot),

      sceneT,

            durationInFrames={durationInFrames}
            layout="none"
            name={`${scene.id} · ${scene.title}`}

        </ActiveShotContext.Provider>

      </ThreeCanvas>

      {config.audio ? (

/**
 * Turns a film config into a Remotion composition. One film = one folder =
 * one MP4. The folder name should be the slug of the title.
 */
export function defineFilm(config: FilmConfig): Film {
  const fps = config.fps ?? 30;
  const width = config.width ?? 1080;
  const height = config.height ?? 1920;

  if (!config.id.match(/^[a-z0-9]+(-[a-z0-9]+)*$/)) {
    throw new Error(`Film id "${config.id}" must be kebab-case, e.g. "the-schedule".`);
  }
  if (config.scenes.length === 0) throw new Error("A film needs at least one scene.");

  const ids = new Set<string>();
  for (const scene of config.scenes) {
    if (ids.has(scene.id)) throw new Error(`Duplicate scene id "${scene.id}".`);
    ids.add(scene.id);
    if (scene.duration <= 0) throw new Error(`Scene "${scene.id}" needs a positive duration.`);
    if (scene.shots.length === 0) throw new Error(`Scene "${scene.id}" has no shots.`);
    for (const shot of scene.shots) {
      if (!shot.note) throw new Error(`A shot in "${scene.id}" is missing its storytelling note.`);
    }
  }

  const totalSeconds = config.scenes.reduce((a, s) => a + s.duration, 0);
  const durationInFrames = Math.max(1, Math.round(totalSeconds * fps));

  const Component: React.FC = () => <FilmView config={config} />;

  return { ...config, fps, width, height, totalSeconds, durationInFrames, Component };
}

const CACHE = new Map<string, THREE.CanvasTexture>();

const PALETTE = (skin: string, hair: string) => ({
  ".": skin,
  ",": shade(skin, -0.18),
  h: hair,
  H: shade(hair, -0.25),
  b: shade(hair, -0.45),
  // A soft brow: a shadow on the skin, not a black bar. For faces that should read as worry, not threat.
  B: shade(skin, -0.3),
  w: "#efece2",
  p: "#161a22",
  m: "#7a4038",
  r: "#241014",
  t: "#efece2",
  g: "#eaf7ff",
  x: "#0a0e16",
  X: "#0d121c",
  n: "#141b28",
  N: "#1b2333",
});

export type FaceOptions = {
  skin?: string;
  hair?: string;
  /** Add per-pixel skin grain so the face does not look like flat vector art. */
  grain?: number;
  /** Pupil offset: -1 left, 1 right, 0 centre. Gives a held eye-dart. */
  gaze?: -1 | 0 | 1;
};

function buildFaceTexture(rowsIn: string[], key: string, options: FaceOptions): THREE.CanvasTexture {
  const skin = options.skin ?? "#e8b78d";
  const hair = options.hair ?? "#4a2e1c";
  const grain = options.grain ?? 0.05;
  const hit = CACHE.get(key);
  if (hit) return hit;

  const rows = rowsIn;
  if (rows.length !== 8 || rows.some((r) => r.length !== 8)) {
    throw new Error(`Face "${key}" must be an 8×8 pixel map.`);
  }

  const canvas = document.createElement("canvas");
  canvas.width = 8;
  canvas.height = 8;
  const ctx = canvas.getContext("2d")!;
  const pal = PALETTE(skin, hair);
  const rand = mulberry32(hashString(key));

  for (let y = 0; y < 8; y++) {
    for (let x = 0; x < 8; x++) {
      const ch = rows[y][x];
      let color = (pal as Record<string, string>)[ch] ?? skin;
      if (grain > 0 && (ch === "." || ch === ",")) {
        color = shade(color, (rand() * 2 - 1) * grain);
      }
      ctx.fillStyle = color;
      ctx.fillRect(x, y, 1, 1);
    }
  }

  const tex = new THREE.CanvasTexture(canvas);
  tex.magFilter = THREE.NearestFilter;
  tex.minFilter = THREE.NearestFilter;
  tex.colorSpace = THREE.SRGBColorSpace;
  tex.needsUpdate = true;
  CACHE.set(key, tex);
  return tex;
}

/** Returns a cached 8×8 CanvasTexture for a face. */
export function faceTexture(name: FaceName, options: FaceOptions = {}): THREE.CanvasTexture {
  const skin = options.skin ?? "#e8b78d";
  const hair = options.hair ?? "#4a2e1c";
  const grain = options.grain ?? 0.05;
  const gaze = options.gaze ?? 0;
  const key = `face|${name}|${skin}|${hair}|${grain}|${gaze}`;
  const source = FACES[name] ?? FACES.neutral;
  // Eyes are 2px wide: swapping white/pupil moves the pupil one pixel and reads
  // as a glance. Do it per pair so both eyes look the same way.
  const rows =
    gaze === 0
      ? source
      : source.map((row) => (gaze > 0 ? row.replace(/pw/g, "wp") : row.replace(/wp/g, "pw")));
  return buildFaceTexture(rows, key, options);
}

/**
 * The same face with the eyes shut. Whites become skin, pupils become a thin
 * shadow line, so a blink reads at a glance instead of looking like a new face.
 * Faces with glowing eyes (hollow) do not blink.
 */
export function blinkFaceTexture(name: FaceName, options: FaceOptions = {}): THREE.CanvasTexture {
  const skin = options.skin ?? "#e8b78d";
  const hair = options.hair ?? "#4a2e1c";
  const grain = options.grain ?? 0.05;
  const key = `blink|${name}|${skin}|${hair}|${grain}`;

  const source = FACES[name] ?? FACES.neutral;
  const hasOpenEyes = source.some((row) => /[wp]/.test(row));

  if (!hasOpenEyes) {
    return buildFaceTexture(source, key, options);
  }

  const rows = source.map((row) =>
    row
      .split("")
      .map((ch) => {
        if (ch === "w") return ".";
        if (ch === "p") return ",";
        return ch;
      })
      .join(""),
  );

  return buildFaceTexture(rows, key, options);
}

import { Euler, Matrix4 } from 'three';
import type { Pose } from './anim';
import type { Vec3 } from './math';

export const PX = 1.8 / 32;

// Pixel boxes below the knee, in the same local coordinates used by the avatar mesh.
export const shin = { center: [0, -3, 0], size: [3.6, 6, 4] } as const;
export const trainer = { center: [0, -5.1, .5], size: [4.1, 2, 5.4] } as const;
export const sole = { center: [0, -5.9, .5], size: [4.2, .6, 5.5] } as const;
type PixelBox = { center: readonly [number, number, number]; size: readonly [number, number, number] };
export const metres = (xyz: readonly [number, number, number]): Vec3 => [xyz[0] * PX, xyz[1] * PX, xyz[2] * PX];
const rotate = (xyz: Vec3) => new Matrix4().makeRotationFromEuler(new Euler(...xyz));

// Project the turned box onto the vertical axis. Its lower edge is its centre minus
// the projections of its three half-edges; the foot need not be flat on the floor.
function bottom(m: Matrix4, { center, size }: PixelBox) {
  const e = m.elements, [x, y, z] = center, [w, h, d] = size;
  return e[13] + e[1]*x + e[5]*y + e[9]*z - (Math.abs(e[1])*w + Math.abs(e[5])*h + Math.abs(e[9])*d)/2;
}

/** Hip height (before avatar scale) that puts the lowest shin/shoe corner on
 * the actor's local y=0. Opt in for grounded steps; NOT for a jump or a seat. */
export function groundedHip(p: Pose, bodyRotation: Vec3, shoes: boolean) {
  const body = rotate(bodyRotation);
  let low = Infinity;
  for (const right of [true, false]) {
    const knee = body.clone().multiply(new Matrix4().makeTranslation(right ? 2.2 : -2.2, 0, 0))
      .multiply(rotate(right ? p.legR : p.legL)).multiply(new Matrix4().makeTranslation(0, -6, 0))
      .multiply(rotate(right ? p.kneeR : p.kneeL));
    low = Math.min(low, bottom(knee, shin));
    if (shoes) low = Math.min(low, bottom(knee, trainer), bottom(knee, sole));
  }
  return -low * PX;
}

  const seeds = useMemo(() => {
    const rand = mulberry32(seed);
    return Array.from({ length: count }, () => ({
      x: (rand() - 0.5) * area[0],
      y: (rand() - 0.5) * area[1],

      phase: rand() * Math.PI * 2,

  const positions = new Float32Array(count * 3);

    const s = seeds[i];
    positions[i * 3] = s.x + Math.sin(t * s.rate + s.phase) * s.drift;

    positions[i * 3 + 2] = s.z + Math.cos(t * s.rate * 0.9 + s.phase) * s.drift;

  return (
    <points position={position} geometry={geometry} frustumCulled={false}>
      <pointsMaterial
        map={glowTex()}
        color={color}
        size={size}
        sizeAttenuation
        transparent
        opacity={opacity}
        depthWrite={false}
        blending={THREE.AdditiveBlending}

/**
 * Locomotion and performance helpers.
 *
 * `useWalkPath` moves an actor along a real curve and reports how far they have
 * travelled. Feed that distance into `MinecraftAvatar` and the legs are driven by
 * ground travel instead of the clock — the feet can no longer skate.
 *
 * `usePerformance` plays a list of clips in order, blending across the joins, so
 * a character can stand up, walk, stop and look around without pose pops.
 */

export type WalkPathOptions = {

  ease?: EaseName;
  /** Fixed facing yaw in radians. Default: face along the direction of travel. */
  yaw?: number;
  /** Seconds to hold at the start before moving. */
  delay?: number;
  /** Seconds to hold at the end after arriving. */
  tail?: number;
  /** Vertical bow in metres, for a gentle rise/fall over the move. */
  arc?: number;

  lookAhead?: number;

export type WalkState = {
  position: Vec3;
  yaw: number;
  /** Metres travelled so far. Feed to the avatar's `animDistance`. */
  distance: number;
  /** Instantaneous ground speed in m/s. */
  speed: number;
  /**
   * Head yaw relative to the body, radians. Feed to the avatar's `headYaw` so
   * the head leads a turn instead of arriving with the shoulders.

  headYaw: number;

type Sample = { point: THREE.Vector3; tangent: THREE.Vector3; arc: number };

function buildSamples(points: Vec3[], segments: number): { samples: Sample[]; total: number } {
  const curve =
    points.length === 2
      ? new THREE.LineCurve3(
          new THREE.Vector3(points[0][0], points[0][1], points[0][2]),
          new THREE.Vector3(points[1][0], points[1][1], points[1][2]),
        )
      : new THREE.CatmullRomCurve3(
          points.map((p) => new THREE.Vector3(p[0], p[1], p[2])),
          false,
          "centripetal",
          0.5,
        );

  const samples: Sample[] = [];
  let total = 0;
  let prev = curve.getPoint(0);
  samples.push({ point: prev.clone(), tangent: new THREE.Vector3(0, 0, 1), arc: 0 });

  for (let i = 1; i <= segments; i++) {
    const u = i / segments;
    const point = curve.getPoint(u);
    total += point.distanceTo(prev);
    const tangent = point.clone().sub(prev);
    if (tangent.lengthSq() < 1e-10) tangent.set(0, 0, 1);
    tangent.normalize();
    samples.push({ point, tangent, arc: total });
    prev = point;
  }

  return { samples, total };
}

function sampleAt(samples: Sample[], total: number, arc: number): Sample {
  if (arc <= 0) return samples[0];
  if (arc >= total) return samples[samples.length - 1];
  let lo = 0;
  let hi = samples.length - 1;
  while (lo + 1 < hi) {
    const mid = (lo + hi) >> 1;
    if (samples[mid].arc <= arc) lo = mid;
    else hi = mid;
  }
  const a = samples[lo];
  const b = samples[hi];
  const span = Math.max(b.arc - a.arc, 1e-6);
  const k = (arc - a.arc) / span;
  return {
    point: a.point.clone().lerp(b.point, k),
    tangent: a.tangent.clone().lerp(b.tangent, k).normalize(),
    arc,
  };
}

export function useWalkPath(options: WalkPathOptions): WalkState {
  const frame = useCurrentFrame();
  const { fps } = useVideoConfig();
  const t = frame / fps;

  const { points, duration, ease = "inOutSine", yaw, delay = 0, tail = 0, arc = 0, lookAhead = 0.7 } = options;

  const { samples, total } = useMemo(() => buildSamples(points, 480), [points]);

  return useMemo(() => {
    const travel = Math.max(1e-3, duration - delay - tail);
    const dt = 1 / Math.max(fps, 1);

    const evalAt = (time: number) => {
      const raw = clamp01((time - delay) / travel);
      const eased = easings[ease](raw);
      return { raw, eased, sample: sampleAt(samples, total, eased * total) };
    };

    const now = evalAt(t);
    const before = evalAt(t - dt);

    const moving = now.raw > 1e-4 && now.raw < 1 - 1e-4;
    const speed = moving ? Math.max(0, now.sample.arc - before.sample.arc) / dt : 0;

    const position: Vec3 = [
      now.sample.point.x,
      now.sample.point.y + (arc !== 0 ? Math.sin(Math.PI * now.eased) * arc : 0),
      now.sample.point.z,
    ];

    const facing = yaw !== undefined ? yaw : Math.atan2(now.sample.tangent.x, now.sample.tangent.z);

    // Head-lead: sample the tangent a little further along the path and turn the
    // head toward it before the body gets there. Damped at rest.
    const ahead = sampleAt(samples, total, Math.min(total, now.sample.arc + lookAhead));
    const aheadYaw = Math.atan2(ahead.tangent.x, ahead.tangent.z);
    let lead = aheadYaw - facing;
    while (lead > Math.PI) lead -= Math.PI * 2;
    while (lead < -Math.PI) lead += Math.PI * 2;
    const headYaw = clamp(lead, -0.55, 0.55) * (moving ? 1 : 0.45);

    return {
      position,
      yaw: facing,
      distance: now.sample.arc,
      speed,
      headYaw,
      progress: now.eased,
      moving,
    };
  }, [samples, total, t, duration, delay, tail, ease, yaw, arc, fps, lookAhead]);
}

export type PerformanceStep = {
  /** Seconds into the scene when this clip starts. */
  at: number;
  clip: AnimName;
  /** Seconds of blend into this clip from the previous one. Default 0.18. */
  blend?: number;
  /** Clip speed multiplier. */
  speed?: number;
};

export type PerformanceState = {
  clip: AnimName;
  /** Local seconds inside the current clip. */
  local: number;
  /** Previous clip while blending, otherwise null. */
  blendTo: AnimName | null;
  /** 0 = previous pose, 1 = current pose. */
  blendK: number;
  /** Local seconds inside the previous clip, so a blend never snaps back to its start. */
  prevLocal: number | null;
  speed: number;
};

/**
 * Plays a list of clips in order. Every step is continuous in time, so blending
 * two poses never pops even when the previous clip was mid-stride.
 */
export function usePerformance(steps: PerformanceStep[]): PerformanceState {
  const frame = useCurrentFrame();
  const { fps } = useVideoConfig();
  const t = frame / fps;

  return useMemo(() => {
    if (steps.length === 0) {
      return { clip: "idle" as AnimName, local: t, blendTo: null, blendK: 1, prevLocal: null, speed: 1 };
    }

    let index = 0;
    for (let i = 0; i < steps.length; i++) {
      if (steps[i].at <= t + 1e-6) index = i;
    }

    const step = steps[index];
    const local = Math.max(0, t - step.at);
    const blend = step.blend ?? 0.18;
    const prev = index > 0 ? steps[index - 1] : undefined;

    if (prev && blend > 0 && local < blend) {
      return {
        clip: step.clip,
        local,
        blendTo: prev.clip,
        blendK: smoothstep(local / blend),
        prevLocal: Math.max(0, t - prev.at),
        speed: step.speed ?? 1,
      };
    }

    return { clip: step.clip, local, blendTo: null, blendK: 1, prevLocal: null, speed: step.speed ?? 1 };
  }, [steps, t]);
}

export const Look: React.FC<{ preset?: LookPreset; post?: PostSettings; focus?: Vec3 }> = ({
  preset = "hospital-night",
  post,
  focus,
}) => {
  const look = LOOKS[preset] ?? LOOKS["hospital-night"];
  // Presets are stable: a fresh vector here would rebuild the sky material on every film frame.
  const sunDir = useMemo(() => new THREE.Vector3(...(look.sky?.sunDir ?? look.key?.position ?? [6, 10, 4])), [look]);
  const span = look.shadowSpan ?? 9;
  const keyRef = useRef<THREE.DirectionalLight>(null);
  const follow = look.follow && focus ? focus : null;
  const keyPosition: Vec3 =
    follow && look.key
      ? [follow[0] + look.key.position[0], follow[1] + look.key.position[1], follow[2] + look.key.position[2]]
      : (look.key?.position ?? [0, 0, 0]);

  // A directional light aims at its `target`, which is not in the scene graph,
  // so its matrix has to be refreshed by hand when the sun follows a subject.
  useFrame(() => {
    const light = keyRef.current;
    if (!light) return;
    if (follow) light.target.position.set(follow[0], follow[1], follow[2]);
    else light.target.position.set(0, 0, 0);
    light.target.updateMatrixWorld();
  });

  return (
    <>
      <color attach="background" args={[look.bg]} />
      {look.sky ? (
        <Sky
          sky={look.sky}
          sunDir={sunDir}
        />
      ) : null}
      <fogExp2 attach="fog" args={[look.fog, look.fogDensity]} />
      <Exposure value={post?.exposure ?? 1.05} />

      <ambientLight color={look.ambient.color} intensity={look.ambient.intensity} />
      <hemisphereLight color={look.hemi.sky} groundColor={look.hemi.ground} intensity={look.hemi.intensity} />

      {look.key && (
        <directionalLight
          ref={keyRef}
          color={look.key.color}
          intensity={look.key.intensity}
          position={keyPosition}
          castShadow={look.key.shadow}
          shadow-mapSize={[2048, 2048]}
          shadow-camera-left={-span}
          shadow-camera-right={span}
          shadow-camera-top={span}
          shadow-camera-bottom={-span}
          shadow-camera-near={0.5}
          shadow-camera-far={40 + span}
          shadow-bias={-0.0006}
          shadow-normalBias={0.02}
        />
      )}

      {look.fills.map((fill, i) => (

          key={i}
          color={fill.color}
          intensity={fill.intensity}

/** Deterministic light flicker, driven by the film clock. */
export const useFlicker = (base: number, windows: Array<[number, number]>, seed = 1): number => {
  const frame = useCurrentFrame();
  const { fps } = useVideoConfig();
  const t = frame / fps;
  let amount = 1;
  for (const [a, b] of windows) {
    const env = pulse(t, a, b);
    if (env > 0) {
      const n = 0.5 + 0.5 * wobble(t * 26 + seed * 3, seed);
      amount = Math.min(amount, 1 - env * (1 - n) * 1.15);
    }
  }
  return Math.max(0.02, base * amount);
};

import * as THREE from "three";

export type Vec3 = [number, number, number];

export const clamp = (v: number, lo = 0, hi = 1) => Math.min(hi, Math.max(lo, v));
export const clamp01 = (v: number) => clamp(v, 0, 1);
export const lerp = (a: number, b: number, t: number) => a + (b - a) * t;
export const inverseLerp = (a: number, b: number, v: number) => (a === b ? 0 : (v - a) / (b - a));
export const remap = (v: number, a: number, b: number, c: number, d: number) =>
  lerp(c, d, clamp01(inverseLerp(a, b, v)));
export const smoothstep = (t: number) => t * t * (3 - 2 * t);
export const TAU = Math.PI * 2;

/**
 * Vertical field of view (degrees) for a full-frame lens.
 *
 * The sensor is 24mm tall in the vertical 9:16 frame, so `focalMmToFov(35)`
 * returns ~37.8° — the "house lens" from the camera bible. Shots can be written
 * in millimetres and converted here instead of guessing degrees.
 */
export const focalMmToFov = (mm: number, sensorHeightMm = 24): number =>
  (2 * Math.atan(sensorHeightMm / (2 * Math.max(1, mm))) * 180) / Math.PI;

/** Smoothly approach a value, frame-rate independent. */
export const damp = (current: number, target: number, lambda: number, dt: number) =>
  lerp(current, target, 1 - Math.exp(-lambda * dt));

export const vec3 = (v: Vec3) => new THREE.Vector3(v[0], v[1], v[2]);
export const vlerp = (a: Vec3, b: Vec3, t: number): Vec3 => [
  lerp(a[0], b[0], t),
  lerp(a[1], b[1], t),
  lerp(a[2], b[2], t),
];

export type EaseName =
  | "linear"
  | "inSine"
  | "outSine"
  | "inOutSine"
  | "inCubic"
  | "outCubic"
  | "inOutCubic"
  | "outQuint"
  | "outExpo"
  | "inOutQuint"
  | "outBack"
  | "hold";

export const easings: Record<EaseName, (t: number) => number> = {
  linear: (t) => t,
  inSine: (t) => 1 - Math.cos((t * Math.PI) / 2),
  outSine: (t) => Math.sin((t * Math.PI) / 2),
  inOutSine: (t) => -(Math.cos(Math.PI * t) - 1) / 2,
  inCubic: (t) => t * t * t,
  outCubic: (t) => 1 - Math.pow(1 - t, 3),
  inOutCubic: (t) => (t < 0.5 ? 4 * t * t * t : 1 - Math.pow(-2 * t + 2, 3) / 2),
  outQuint: (t) => 1 - Math.pow(1 - t, 5),
  outExpo: (t) => (t >= 1 ? 1 : 1 - Math.pow(2, -10 * t)),
  inOutQuint: (t) => (t < 0.5 ? 16 * t ** 5 : 1 - Math.pow(-2 * t + 2, 5) / 2),
  outBack: (t) => {
    const c1 = 1.70158;
    const c3 = c1 + 1;
    return 1 + c3 * Math.pow(t - 1, 3) + c1 * Math.pow(t - 1, 2);
  },
  hold: () => 0,
};

/** Deterministic PRNG. Never use Math.random() in a film — it breaks rendering. */
export function mulberry32(seed: number): () => number {
  let a = seed >>> 0;
  return () => {
    a = (a + 0x6d2b79f5) >>> 0;
    let t = Math.imul(a ^ (a >>> 15), 1 | a);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}

export function hashString(s: string): number {
  let h = 2166136261;
  for (let i = 0; i < s.length; i++) {
    h ^= s.charCodeAt(i);
    h = Math.imul(h, 16777619);
  }
  return h >>> 0;
}

/** Cheap deterministic organic noise built from sines. Range roughly -1..1. */
export function wobble(t: number, seed = 0): number {
  return (
    Math.sin(t * 1.13 + seed * 1.7) * 0.5 +
    Math.sin(t * 2.71 + seed * 3.1) * 0.3 +
    Math.sin(t * 5.37 + seed * 7.3) * 0.2
  );
}

/** 0 → 1 → 0 pulse over [a,b] seconds. */
export function pulse(t: number, a: number, b: number): number {
  if (t <= a || t >= b) return 0;
  const p = inverseLerp(a, b, t);
  return Math.sin(p * Math.PI);
}

/** Shade a hex colour by `amount` (-1..1). */
export function shade(hex: string, amount: number): string {
  const c = hex.replace("#", "");
  const full = c.length === 3 ? c.split("").map((x) => x + x).join("") : c;
  const n = parseInt(full, 16);
  const r = (n >> 16) & 255;
  const g = (n >> 8) & 255;
  const b = n & 255;
  const f = (v: number) =>
    Math.round(amount >= 0 ? v + (255 - v) * amount : v * (1 + amount));
  return `#${[f(r), f(g), f(b)].map((v) => v.toString(16).padStart(2, "0")).join("")}`;
}

/** Deterministic blink envelope: closed for ~0.13s every 2.6–4.8s. */
function blinkAmount(time: number, phase: number): number {
  const period = 2.6 + (Math.abs(phase) % 1.6);
  const local = ((time + phase) % period + period) % period;
  if (local > 0.13) return 0;
  return Math.sin((local / 0.13) * Math.PI);
}

  arms,
  blendTo,

  const shiftAmt = weightShift * (travelling ? 0.18 : 1);

  ".": [0x60, 0x60], ",": [0x50, 0x30], " ": [0x00, 0x00, 0x00],
};

export const GLYPH_ROWS = 7;

/** The word as a grid of 0/1, one row per string of the result. */
export function wordBitmap(text: string): { width: number; rows: Uint8Array[] } {
  const cols: number[] = [];
  for (const ch of text) {
    const glyph = G[ch] ?? G[ch.toUpperCase()] ?? G["?"];
    if (cols.length > 0) cols.push(0);
    cols.push(...glyph);
  }
  const rows: Uint8Array[] = [];
  for (let y = 0; y < GLYPH_ROWS; y++) {
    rows.push(Uint8Array.from(cols, (c) => (c >> y) & 1));
  }
  return { width: cols.length, rows };
}

const CACHE = new Map<string, THREE.DataTexture>();

/**
 * White letters, a one-pixel black outline all round, and one more pixel of
 * black down-right as a drop shadow. Transparent elsewhere.
 */
export function wordTexture(text: string): THREE.DataTexture {
  const hit = CACHE.get(text);
  if (hit) return hit;

  const { width, rows } = wordBitmap(text);
  const pad = 2; // outline + shadow
  const w = width + pad * 2;
  const h = GLYPH_ROWS + pad * 2;
  const data = new Uint8Array(w * h * 4);
  const lit = (x: number, y: number) => x >= 0 && y >= 0 && x < width && y < GLYPH_ROWS && rows[y][x] === 1;

  for (let y = 0; y < h; y++) {
    for (let x = 0; x < w; x++) {
      const gx = x - pad;
      const gy = y - pad;
      let value = -1; // -1 clear, 0 black, 1 white
      if (lit(gx, gy)) value = 1;
      else {
        outer: for (let dy = -1; dy <= 1; dy++) {
          for (let dx = -1; dx <= 1; dx++) {
            if (lit(gx + dx, gy + dy)) {
              value = 0;
              break outer;
            }
          }
        }
        if (value < 0 && (lit(gx - 2, gy - 2) || lit(gx - 1, gy - 2) || lit(gx - 2, gy - 1))) value = 0;
      }
      // DataTexture row 0 is the BOTTOM of the image.
      const i = ((h - 1 - y) * w + x) * 4;
      if (value >= 0) {
        data[i] = data[i + 1] = data[i + 2] = value * 255;
        data[i + 3] = 255;
      }
    }
  }

  const tex = new THREE.DataTexture(data, w, h, THREE.RGBAFormat);
  tex.magFilter = THREE.NearestFilter;
  tex.minFilter = THREE.NearestFilter;
  tex.generateMipmaps = false;
  tex.needsUpdate = true;
  CACHE.set(text, tex);
  return tex;
}

import { useFrame, useThree } from "@react-three/fiber";
import * as THREE from "three";
import { useCurrentFrame, useVideoConfig } from "remotion";
import { EffectComposer } from "three/examples/jsm/postprocessing/EffectComposer.js";
import { RenderPass } from "three/examples/jsm/postprocessing/RenderPass.js";
import { ShaderPass } from "three/examples/jsm/postprocessing/ShaderPass.js";
import { UnrealBloomPass } from "three/examples/jsm/postprocessing/UnrealBloomPass.js";
import { OutputPass } from "three/examples/jsm/postprocessing/OutputPass.js";
import type { ShaderSettings, SkySettings } from "./types";

/** The name the sky dome answers to, so the shaft pass can find the sun without a global. */
const SKY_NAME = "shader-sky";

/**
 * The sky, as a shader.
 *
 * A flat `<color background>` is the single biggest reason our outdoor shots read as "a game engine"
 * instead of "a morning". This dome paints a real vertical gradient, cloud, a haze band at the
 * horizon, and a sun with a halo bright enough for the bloom pass and the shaft pass to catch.
 *
 * The clouds are the part that matters most. Measured against the reference film, our sky had a
 * `sky texture` of 1.0-3.3 where theirs has 7.2: theirs has something in it, ours was a wash. They
 * are value noise on the view direction projected onto a flat layer, which is how every Minecraft
 * shader pack fakes volume without a raymarcher — cheap, and it survives a software renderer.
 */
const SKY_VERT = /* glsl */ `
varying vec3 vDir;
void main() {
  vDir = position;
  gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
}
`;

const SKY_FRAG = /* glsl */ `
varying vec3 vDir;
uniform vec3 uTop;
uniform vec3 uHorizon;
uniform vec3 uBottom;
uniform vec3 uSunColor;
uniform vec3 uCloudShade;
uniform vec3 uSunDir;
uniform float uSunSize;
uniform float uSunPower;
uniform float uHaze;
uniform float uClouds;
uniform float uCloudScale;
uniform float uCloudCover;
uniform float uCloudHeight;
uniform float uDither;
uniform float uTime;

float hash31(vec3 p) {
  p = fract(p * 0.3183099 + vec3(0.71, 0.113, 0.419));
  p *= 17.0;
  return fract(p.x * p.y * p.z * (p.x + p.y + p.z));
}

float vnoise(vec3 x) {
  vec3 i = floor(x);
  vec3 f = fract(x);
  f = f * f * (3.0 - 2.0 * f);
  return mix(
    mix(mix(hash31(i + vec3(0.0, 0.0, 0.0)), hash31(i + vec3(1.0, 0.0, 0.0)), f.x),
        mix(hash31(i + vec3(0.0, 1.0, 0.0)), hash31(i + vec3(1.0, 1.0, 0.0)), f.x), f.y),
    mix(mix(hash31(i + vec3(0.0, 0.0, 1.0)), hash31(i + vec3(1.0, 0.0, 1.0)), f.x),
        mix(hash31(i + vec3(0.0, 1.0, 1.0)), hash31(i + vec3(1.0, 1.0, 1.0)), f.x), f.y), f.z);
}

float fbm(vec3 p) {
  float a = 0.5;
  float s = 0.0;
  for (int i = 0; i < 4; i++) {
    s += a * vnoise(p);
    p *= 2.03;
    a *= 0.5;
  }
  return s;
}

void main() {
  vec3 d = normalize(vDir);
  vec3 s = normalize(uSunDir);
  float h = d.y;
  float sd = max(dot(d, s), 0.0);

  vec3 col = mix(uHorizon, uTop, pow(clamp(h, 0.0, 1.0), 0.40));
  col = mix(col, uBottom, pow(clamp(-h, 0.0, 1.0), 0.42));

  // Cloud: a flat layer overhead, thick where it is thick, thinning towards the horizon the way
  // a layer does when you look along it instead of up through it.
  if (uClouds > 0.001 && h > 0.0) {
    vec3 cp = d / max(h, 0.22) * uCloudHeight;
    cp.x += uTime * 0.35;
    cp.z += uTime * 0.12;
    float cl = fbm(cp * uCloudScale);
    cl = smoothstep(uCloudCover, uCloudCover + 0.30, cl);
    cl *= smoothstep(0.06, 0.40, h);
    // Lit from the sun side, and a bright rim where the sun is straight through it.
    float lit = 0.35 + 0.65 * pow(sd, 3.0);
    float rim = pow(cl, 0.6) * pow(sd, 24.0);
    vec3 cloudCol = mix(uCloudShade, uSunColor, lit) + uSunColor * rim * 0.55;
    col = mix(col, cloudCol, clamp(cl * uClouds, 0.0, 1.0));
  }

  // The sun: a broad glow, a tight disc, and a halo for bloom to catch.
  col += uSunColor * pow(sd, uSunSize) * uSunPower;
  col += uSunColor * pow(sd, 7.0) * 0.30 * uSunPower;
  col += uSunColor * smoothstep(0.99930, 0.99975, sd) * 3.0;

  // Haze thickens towards the horizon, as it does in the reference film.
  float band = pow(1.0 - clamp(abs(h), 0.0, 1.0), 8.0);
  col = mix(col, uHorizon, uHaze * band * 0.55);

  // A gradient this wide bands on an 8-bit frame. Half a level of noise hides it, and it costs
  // nothing next to what banding costs a sky.
  float n = hash31(vec3(gl_FragCoord.xy, uTime));
  col += (n - 0.5) * uDither;

  gl_FragColor = vec4(col, 1.0);
}
`;

export const Sky: React.FC<{ sky: SkySettings; sunDir: THREE.Vector3 }> = ({ sky, sunDir }) => {
  const camera = useThree((s) => s.camera);
  const group = useRef<THREE.Group>(null);
  const dir = useMemo(() => sunDir.clone().normalize(), [sunDir]);
  // Clouds drift on the film's own clock, never on the wall clock: a frame must render the same
  // every time it is rendered, and Actions renders frames in whatever order it likes.
  const frame = useCurrentFrame();
  const { fps } = useVideoConfig();
  const material = useMemo(() => {
    return new THREE.ShaderMaterial({
      vertexShader: SKY_VERT,
      fragmentShader: SKY_FRAG,
      side: THREE.BackSide,
      depthWrite: false,
      fog: false,
      uniforms: {
        uTop: { value: new THREE.Color(sky.top) },
        uHorizon: { value: new THREE.Color(sky.horizon) },
        uBottom: { value: new THREE.Color(sky.bottom ?? sky.horizon) },
        uSunColor: { value: new THREE.Color(sky.sun ?? "#fff4d8") },
        uCloudShade: { value: new THREE.Color(sky.cloudShade ?? "#ffffff") },
        uSunDir: { value: dir.clone() },
        uSunSize: { value: sky.sunSize ?? 220 },
        uSunPower: { value: sky.sunPower ?? 0.9 },
        uHaze: { value: sky.haze ?? 0.55 },
        uClouds: { value: sky.clouds ?? 0 },
        uCloudScale: { value: sky.cloudScale ?? 1.0 },
        uCloudCover: { value: sky.cloudCover ?? 0.48 },
        uCloudHeight: { value: sky.cloudHeight ?? 8 },
        uDither: { value: sky.dither ?? 0.004 },
        uTime: { value: 0 },
      },
    });
  }, [sky, dir]);

  // The camera runs first. Update both position and cloud time before this frame's draw.
  useFrame(() => {
    if (group.current) group.current.position.copy(camera.position);
    material.uniforms.uTime!.value = frame / fps;
  });

  useEffect(() => () => material.dispose(), [material]);

  return (
    <group ref={group}>
      <mesh
        name={SKY_NAME}
        scale={120}
        renderOrder={-1000}
        frustumCulled={false}
        userData={{ sunDir: dir.toArray(), sunColor: sky.sun ?? "#fff4d8" }}
      >
        <sphereGeometry args={[1, 48, 32]} />
        <primitive object={material} attach="material" />
      </mesh>
    </group>
  );
};

/**
 * Volumetric shafts: the classic radial scatter, done on the frame we already have.
 *
 * It samples towards the sun and keeps only what is bright, so light appears to stream from the
 * sun across whatever sits in front of it. It has no depth test, so a roof cannot block a shaft --
 * which is why the default strength is a whisper rather than a shout.
 */
const SHAFT_SAMPLES = 24;

const SHAFT_SHADER = {
  uniforms: {
    tDiffuse: { value: null },
    uSunUv: { value: new THREE.Vector2(0.5, 0.9) },
    uSunVisible: { value: 0 },
    uShafts: { value: 0 },
    uDensity: { value: 0.9 },
    uDecay: { value: 0.96 },
  },
  vertexShader: /* glsl */ `
varying vec2 vUv;
void main() {
  vUv = uv;
  gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
}
`,
  fragmentShader: /* glsl */ `
uniform sampler2D tDiffuse;
uniform vec2 uSunUv;
uniform float uSunVisible;
uniform float uShafts;
uniform float uDensity;
uniform float uDecay;
varying vec2 vUv;

float lum(vec3 c) { return dot(c, vec3(0.2126, 0.7152, 0.0722)); }

void main() {
  vec3 base = texture2D(tDiffuse, vUv).rgb;
  float amount = uShafts * uSunVisible;
  if (amount <= 0.001) {
    gl_FragColor = vec4(base, 1.0);
    return;
  }

  vec2 delta = (vUv - uSunUv) * (uDensity / float(${SHAFT_SAMPLES}));
  vec2 uv = vUv;
  float illum = 1.0;
  vec3 acc = vec3(0.0);
  for (int i = 0; i < ${SHAFT_SAMPLES}; i++) {
    uv -= delta;
    vec3 s = texture2D(tDiffuse, clamp(uv, 0.0, 1.0)).rgb;
    acc += s * smoothstep(0.60, 0.95, lum(s)) * illum;
    illum *= uDecay;
  }
  acc /= float(${SHAFT_SAMPLES});

  gl_FragColor = vec4(base + acc * amount, 1.0);
}
`,
};

/**
 * The grade pass. Sits after bloom and does what a camera and a print do: it spreads a little
 * light through the glass, rolls the highlights off instead of clipping them, lifts the black
 * point the way film does, warms the light and cools the dark, darkens the corners, and lays
 * grain over the whole thing.
 *
 * Every constant here was tuned with `scripts/shader-sim.py`, which pushes a real frame through
 * this same maths and scores it against the reference film. The numbers are not taste; they are
 * the distance between our picture and the one the owner pointed at.
 */
const GRADE_SHADER = {
  uniforms: {
    tDiffuse: { value: null },
    uTexel: { value: new THREE.Vector2(1 / 1080, 1 / 1920) },
    uSat: { value: 1.45 },
    uContrast: { value: 1.05 },
    uShoulder: { value: 0.11 },
    uLift: { value: 0.05 },
    uWarm: { value: 0.95 },
    uCool: { value: 0.5 },
    uVignette: { value: 0.12 },
    uDiffusion: { value: 0.14 },
    uDiffRadius: { value: 6.0 },
    uDiffThreshold: { value: 0.86 },
    uVeil: { value: 0.025 },
    uGrain: { value: 0.011 },
    uAberr: { value: 0.16 },
    uTime: { value: 0 },
  },
  vertexShader: /* glsl */ `
varying vec2 vUv;
void main() {
  vUv = uv;
  gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
}
`,
  fragmentShader: /* glsl */ `
uniform sampler2D tDiffuse;
uniform vec2 uTexel;
uniform float uSat;
uniform float uContrast;
uniform float uShoulder;
uniform float uLift;
uniform float uWarm;
uniform float uCool;
uniform float uVignette;
uniform float uDiffusion;
uniform float uDiffRadius;
uniform float uDiffThreshold;
uniform float uVeil;
uniform float uGrain;
uniform float uAberr;
uniform float uTime;
varying vec2 vUv;

float lum(vec3 c) { return dot(c, vec3(0.2126, 0.7152, 0.0722)); }

void main() {
  vec2 uv = vUv;
  vec2 d = uv - 0.5;
  float r2 = dot(d, d);

  // Lens fringing: zero in the centre, a pixel or two at the corners.
  float ab = uAberr * r2 * 0.006;
  vec3 c;
  c.r = texture2D(tDiffuse, uv + d * ab).r;
  c.g = texture2D(tDiffuse, uv).g;
  c.b = texture2D(tDiffuse, uv - d * ab).b;

  float l0 = lum(c);

  // How soft is this pixel's neighbourhood? A gradient is soft; the edge of a white caption is
  // not. Diffusion must not take light from a caption, so it is masked by this.
  vec3 ring = texture2D(tDiffuse, uv + vec2( 2.0, 0.0) * uTexel).rgb
            + texture2D(tDiffuse, uv + vec2(-2.0, 0.0) * uTexel).rgb
            + texture2D(tDiffuse, uv + vec2( 0.0, 2.0) * uTexel).rgb
            + texture2D(tDiffuse, uv + vec2( 0.0,-2.0) * uTexel).rgb;
  float edge = abs(l0 - lum(ring * 0.25));
  float soft = 1.0 - clamp((edge - 0.05) / 0.20, 0.0, 1.0);

  // Pro-mist: light spread through glass. Two rings of taps, one ring weighted towards what is
  // bright (the mist) and one plain (veiling glare, which lifts the shadows).
  vec2 step1 = uTexel * uDiffRadius;
  vec2 step2 = uTexel * uDiffRadius * 2.1;
  vec3 allSum = vec3(0.0);
  vec3 hotSum = vec3(0.0);
  float hotW = 0.0;
  for (int i = 0; i < 6; i++) {
    float a = float(i) * 1.0472; // six taps around the circle
    vec2 o1 = vec2(cos(a), sin(a));
    vec2 o2 = vec2(cos(a + 0.5236), sin(a + 0.5236));
    vec3 s1 = texture2D(tDiffuse, uv + o1 * step1).rgb;
    vec3 s2 = texture2D(tDiffuse, uv + o2 * step2).rgb;
    allSum += s1 + s2;
    float w1 = clamp((lum(s1) - uDiffThreshold) / (1.0 - uDiffThreshold), 0.0, 1.0) * soft;
    float w2 = clamp((lum(s2) - uDiffThreshold) / (1.0 - uDiffThreshold), 0.0, 1.0) * soft;
    hotSum += s1 * w1 + s2 * w2;
    hotW += w1 + w2;
  }
  c += (allSum / 12.0) * uVeil;
  c += (hotSum / 12.0) * uDiffusion;

  c = clamp(c, 0.0, 1.0);

  // Saturation, then the filmic curve: contrast about the middle, and a shoulder so bright
  // things roll off the way film does instead of turning into paper.
  float l1 = lum(c);
  c = l1 + (c - l1) * uSat;
  c = (c - 0.5) * uContrast + 0.5;
  c = c - uShoulder * pow(max(c, vec3(0.0)), vec3(3.0));
  c = clamp(c, 0.0, 1.0);

  // Lift: film does not reach black, it reaches a dark warm grey. This is most of the difference
  // between a picture that was rendered and one that was photographed.
  float l2 = lum(c);
  vec3 tint = vec3(1.10, 1.00, 0.94);
  c += uLift * tint * (1.0 - pow(clamp(l2 / 0.32, 0.0, 1.0), 1.3));

  // Split tone: warm from the midtones up, cool only in the deepest part of the range. Warming
  // the highlights alone cools a dark film overall, which is the opposite of what it needs.
  float l3 = lum(c);
  float hi = pow(clamp((l3 - 0.18) / 0.55, 0.0, 1.0), 1.15);
  float lo = 1.0 - pow(clamp(l3 / 0.18, 0.0, 1.0), 1.4);
  c += uWarm * vec3(0.105, 0.024, -0.070) * hi;
  c += uWarm * uCool * vec3(-0.020, -0.002, 0.030) * lo;

  // Vignette.
  float v = 1.0 - uVignette * pow(clamp((r2 * 2.6 - 0.06) / 0.9, 0.0, 1.0), 1.35);
  c *= v;

  // Grain: strongest in the middle of the range, as film grain is, and it doubles as the dither
  // that keeps a wide sky from banding.
  float n = fract(sin(dot(uv * vec2(1.0, 1.7) + uTime * 0.37, vec2(12.9898, 78.233))) * 43758.5453);
  float weight = clamp(1.0 - abs(lum(c) - 0.45) / 0.6, 0.15, 1.0);
  c += (n - 0.5) * uGrain * weight;

  gl_FragColor = vec4(clamp(c, 0.0, 1.0), 1.0);
}
`,
};

export const DEFAULT_SHADERS: Required<ShaderSettings> = {
  enabled: true,
  // Tuned against a still render: 0.8 / 0.55 melted white sleeves and skin.
  // Bloom is now only for things that are actually light — the sun, torches,
  // lanterns, glow cards — not for pale materials in a bright room.
  bloom: 0.55,
  // Threshold is in linear light, where a white caption is exactly 1.0 and the
  // sun disc is far above it. Set above 1 so words stay crisp and only light blooms.
  threshold: 1.25,
  radius: 0.6,
  vignette: 0.12,
  saturation: 1.45,
  contrast: 1.05,
  warmth: 0.95,
  grain: 0.011,
  aberration: 0.16,
  // The rest were tuned with scripts/shader-sim.py against the reference film.
  diffusion: 0.14,
  veil: 0.025,
  lift: 0.05,
  shoulder: 0.11,
  coolShadow: 0.5,
  shafts: 0.3,

const resolve = (s?: ShaderSettings | boolean): Required<ShaderSettings> | null => {
  if (!s) return null;
  if (s === true) return DEFAULT_SHADERS;
  if (s.enabled === false) return null;
  return { ...DEFAULT_SHADERS, ...s };
};

/** Where the sun is on screen this frame, and whether it is worth drawing shafts for. */
const useSunOnScreen = () => {
  const scene = useThree((s) => s.scene);
  const camera = useThree((s) => s.camera);
  const found = useRef<THREE.Object3D | null>(null);
  return (): { uv: THREE.Vector2; visible: number } => {
    if (found.current?.parent?.parent !== scene) found.current = scene.getObjectByName(SKY_NAME) ?? null;
    const sky = found.current;
    if (!sky) return { uv: new THREE.Vector2(0.5, 1.0), visible: 0 };
    const sd = sky.userData?.sunDir as number[] | undefined;
    if (!sd) return { uv: new THREE.Vector2(0.5, 1.0), visible: 0 };
    const dir = new THREE.Vector3(sd[0], sd[1], sd[2]).normalize();
    const forward = camera.getWorldDirection(new THREE.Vector3());
    const facing = forward.dot(dir);
    const p = new THREE.Vector3().copy(camera.position).addScaledVector(dir, 60).project(camera);
    const uv = new THREE.Vector2(p.x * 0.5 + 0.5, p.y * 0.5 + 0.5);
    // Behind the camera: nothing. Near the frame: full. Far outside it: nothing, because a shaft
    // you cannot see the source of is only streak.
    const onScreen = 1 - THREE.MathUtils.smoothstep(uv.distanceTo(new THREE.Vector2(0.5, 0.5)), 0.35, 1.1);
    const visible = Math.max(0, Math.min(1, facing * 1.6)) * onScreen * (p.z > 1 ? 0 : 1);
    return { uv, visible };
  };
};

/**
 * Real post-processing: bloom, shafts, grade, vignette, grain.
 *
 * R3F stops rendering the scene itself as soon as a `useFrame` callback with a
 * positive priority exists, so this component owns the frame from then on.
 */
export const PostFX: React.FC<{ settings?: ShaderSettings | boolean }> = ({ settings }) => {
  // Do not subscribe at positive priority when disabled: it takes over R3F's draw
  // even if the callback returns without drawing anything. Film config is stable.
  const cfg = useMemo(() => resolve(settings), [settings]);
  return cfg ? <ComposedFrame cfg={cfg} /> : null;
};

const ComposedFrame: React.FC<{ cfg: Required<ShaderSettings> }> = ({ cfg }) => {
  const gl = useThree((s) => s.gl);
  const scene = useThree((s) => s.scene);
  const camera = useThree((s) => s.camera);
  const size = useThree((s) => s.size);
  const sunOnScreen = useSunOnScreen();

  const active = useRef<{ composer: EffectComposer; shafts: ShaderPass; grade: ShaderPass } | null>(null);
  useLayoutEffect(() => {
    const composer = new EffectComposer(gl);
    composer.setPixelRatio(1);
    composer.setSize(size.width, size.height);
    if (composer.renderTarget1) composer.renderTarget1.samples = 4;
    if (composer.renderTarget2) composer.renderTarget2.samples = 4;

    const render = new RenderPass(scene, camera);
    const bloom = new UnrealBloomPass(
      new THREE.Vector2(size.width, size.height),
      cfg.bloom,
      cfg.radius,
      cfg.threshold,
    );
    const shafts = new ShaderPass(SHAFT_SHADER);
    const grade = new ShaderPass(GRADE_SHADER);
    // A composer renders into a render target, and three only applies tone
    // mapping when it draws to the canvas — so without an OutputPass the film
    // comes out linear and dark. Bloom first (in linear light), then ACES plus
    // sRGB, then everything a camera does to light that has already landed.
    const output = new OutputPass();
    composer.addPass(render);
    composer.addPass(bloom);
    composer.addPass(output);
    composer.addPass(shafts);
    composer.addPass(grade);
    grade.renderToScreen = true;
    // ShaderPass clones the uniforms of a plain shader object, so the two passes cannot share one.
    const u = grade.material.uniforms;
    u.uVignette!.value = cfg.vignette;
    u.uSat!.value = cfg.saturation;
    u.uContrast!.value = cfg.contrast;
    u.uShoulder!.value = cfg.shoulder;
    u.uLift!.value = cfg.lift;
    u.uWarm!.value = cfg.warmth;
    u.uCool!.value = cfg.coolShadow;
    u.uDiffusion!.value = cfg.diffusion;
    u.uVeil!.value = cfg.veil;
    u.uGrain!.value = cfg.grain;
    u.uAberr!.value = cfg.aberration;
    u.uTexel!.value = new THREE.Vector2(1 / size.width, 1 / size.height);

    shafts.material.uniforms.uShafts!.value = cfg.shafts;
    active.current = { composer, shafts, grade };
    return () => {
      active.current = null;
      for (const pass of composer.passes) pass.dispose();
      composer.dispose();
    };
  }, [gl, scene, camera, cfg, size.width, size.height]);

  const filmFrame = useCurrentFrame();
  const { fps } = useVideoConfig();
  useFrame((_, delta) => {
    const rig = active.current;
    if (!rig) { gl.render(scene, camera); return; }
    const g = rig.grade.material.uniforms;
    if (g) g.uTime!.value = filmFrame / fps;
    const s = rig.shafts.material.uniforms;
    if (s) {
      const sun = sunOnScreen();
      s.uSunUv!.value = sun.uv;
      s.uSunVisible!.value = sun.visible;
    }
    rig.composer.render(delta);
  }, 1);

  return null;
};

import { Fragment } from "react";
import type React from "react";
import { useActiveShot, useTime } from "./defineFilm";

import type { CaptionWord, SceneDef, Shot } from "./types";

/**
 * STORY FILMS — the narration is the clock.
 *
 * In a narrated, fast-cut film nobody types `at: 12.4`. The voice is recorded,
 * `scripts/narration.py` measures when each word is said, and every shot is
 * tied to the words spoken over it (a CUE). Change the script, rebuild the
 * timing, and all 80 cuts move with it.
 *
 *   narration.md  →  audio  →  timing.json  →  storyScene(timing, …)
 */

export type Timing = {
  fps: number;
  /** Whole film, seconds. */
  duration: number;
  /** Legacy summary: true if no words were measured. False does not rule out a guessed clip. */
  estimated?: boolean;
  /** Written by new builds. Archived clocks may only record the method per clip. */
  wordTiming?: "estimated" | "aligned" | "partial";
  cues: Array<{ id: string; start: number; end: number; text: string }>;
  words: CaptionWord[];
};

export type StageInfo = {
  /** Length of this shot in seconds. */
  dur: number;
  /** 0 at the cut in, 1 at the cut out. */
  p: number;
};

export type StoryShot = Omit<Shot, "at" | "dur" | "cue"> & {
  /** Id of the narration line this shot is cut to. */
  cue: string;
  /**
   * A cut INSIDE a line. Leave it out and the shot starts with the line. Give seconds (into the line) and this
   * shot takes over from the one before it, which must be on the same cue: an action line can be three or four
   * angles instead of one. `t` in `stage` then counts from this cut, so subtract `cut` from a `wordAt` time.
   */
  cut?: number;
  /**
   * Who and what is in front of the lens for this shot. `t` is seconds since
   * the cut. It is a plain function: do not call hooks in it (return a
   * component that does, if you need one).
   */
  stage?: (t: number, info: StageInfo) => React.ReactNode;
};

export type StorySceneDef = {
  id: string;
  title: string;
  shots: StoryShot[];
  /** Optional: things that stay for the whole scene. */
  Component?: React.FC;
};

function cueOf(timing: Timing, id: string, sceneId: string) {
  const cue = timing.cues.find((c) => c.id === id);
  if (!cue) {
    throw new Error(
      `[${sceneId}] shot cue "${id}" is not in timing.json. Is the line in narration.md, and did you rebuild the timing?`,
    );
  }
  return cue;
}

/** Build an engine scene whose cuts land on narration cues. */
export function storyScene(timing: Timing, def: StorySceneDef): SceneDef {
  if (def.shots.length === 0) throw new Error(`[${def.id}] a story scene needs at least one shot.`);
  const start = cueOf(timing, def.shots[0].cue, def.id).start;

  let cursor = start;
  let previous = "";
  const begins: number[] = def.shots.map((shot) => {
    const cue = cueOf(timing, shot.cue, def.id);
    if (shot.cut !== undefined && shot.cut > 0) {
      if (shot.cue !== previous) throw new Error(`[${def.id}] shot "${shot.cue}" has \`cut\` but the shot before it is on another cue.`);
      if (cue.start + shot.cut >= cue.end) throw new Error(`[${def.id}] shot "${shot.cue}" cuts at ${shot.cut}s, after its line has ended.`);
      return cue.start + shot.cut;
    }
    if (Math.abs(cue.start - cursor) > 1e-3) {
      throw new Error(
        `[${def.id}] cue "${shot.cue}" starts at ${cue.start}s but the previous shot ends at ${cursor.toFixed(3)}s. ` +
          `Shots in a scene must follow narration.md line by line, with none skipped.`,
      );
    }
    cursor = cue.end;
    previous = shot.cue;
    return cue.start;
  });
  const shots: Shot[] = def.shots.map((shot, i) => {
    const cue = cueOf(timing, shot.cue, def.id);
    const next = def.shots[i + 1];
    const end = next && next.cut !== undefined && next.cut > 0 ? begins[i + 1] : cue.end;
    if (end - begins[i] < 0.1) throw new Error(`[${def.id}] shot ${i} on "${shot.cue}" is shorter than a tenth of a second.`);
    const { stage: _stage, cut: _cut, ...camera } = shot;
    return { ...camera, at: begins[i] - start, dur: end - begins[i] };
  });

  const sampleStage = (index: number, local: number) => {
    const dur = shots[index].dur;
    return def.shots[index].stage?.(local, { dur, p: clamp01(local / dur) });
  };
  const Component: React.FC = () => {
    const t = useTime();
    let index = 0;
    for (let i = 0; i < shots.length; i++) if (shots[i].at <= t + 1e-6) index = i;
    const local = t - shots[index].at;
    return (
      <>
        {def.Component ? <def.Component /> : null}
        {/* The key remounts the stage on every cut, so one shot's state never leaks into the next. */}
        <Fragment key={`${def.shots[index].cue}#${index}`}>{sampleStage(index, local)}</Fragment>
      </>
    );
  };

  return { id: def.id, title: def.title, duration: cursor - start, shots, Component, sampleStage };
}

/**
 * A part of the world that only exists for some shots. A shot names its zone
 * (`zone: "town"`); every other zone is hidden, lights included, so a film can
 * hold a village, a bedroom and a lava lake without drawing all three.
 * A shot with no zone shows everything. "a+b" shows two zones.
 * `with` lists other zones this one also appears in: a town wall that is seen
 * from the town and from outside it is `<Zone name="wall" with={["town", "lake"]}>`.
 */
export const Zone: React.FC<{ name: string; with?: string[]; children: React.ReactNode }> = ({
  name,
  with: companions = [],
  children,
}) => {
  const active = useActiveShot();
  const zone = active?.shot.zone;
  const on = zone === undefined ? null : zone.split("+");
  const visible = on === null || on.includes(name) || companions.some((other) => on.includes(other));
  return <group visible={visible}>{children}</group>;
};

/**
 * Walk in a straight line during a shot. Spread the result into an avatar:
 *   <Hero {...stride([0,0,0], [0,0,3], p)} animation="walk" />
 * The feet follow the ground because `animDistance` is real metres.
 */
export function stride(a: Vec3, b: Vec3, p: number): { position: Vec3; rotationY: number; animDistance: number } {
  const k = clamp01(p);
  const dx = b[0] - a[0];
  const dz = b[2] - a[2];
  return {
    position: [a[0] + dx * k, a[1] + (b[1] - a[1]) * k, a[2] + dz * k],
    rotationY: Math.atan2(dx, dz),
    animDistance: Math.hypot(dx, dz) * k,
  };
}

import * as THREE from "three";
import { hashString, mulberry32, shade } from "./math";

/**
 * Every texture in this framework is generated procedurally at runtime.
 * No image assets, no downloads, no broken paths — and everything stays
 * pixel-crisp with NearestFilter, which is what makes it read as Minecraft.
 */

const CACHE = new Map<string, THREE.CanvasTexture>();

function texture(
  key: string,
  width: number,
  height: number,
  draw: (ctx: CanvasRenderingContext2D) => void,
  repeat: [number, number] = [1, 1],
): THREE.CanvasTexture {
  const hit = CACHE.get(key);
  if (hit) return hit;

  const canvas = document.createElement("canvas");
  canvas.width = width;
  canvas.height = height;
  draw(canvas.getContext("2d")!);

  const tex = new THREE.CanvasTexture(canvas);
  tex.magFilter = THREE.NearestFilter;
  tex.minFilter = THREE.NearestMipmapLinearFilter;
  tex.wrapS = THREE.RepeatWrapping;
  tex.wrapT = THREE.RepeatWrapping;
  tex.repeat.set(repeat[0], repeat[1]);
  tex.colorSpace = THREE.SRGBColorSpace;
  tex.needsUpdate = true;
  CACHE.set(key, tex);
  return tex;
}

/** Flat colour with subtle per-pixel value noise. The bread and butter of the look. */
export function pixelTex(
  base: string,
  repeat: [number, number] = [1, 1],
  opts: { jitter?: number; size?: number; seed?: number } = {},
): THREE.CanvasTexture {
  const size = opts.size ?? 8;
  const jitter = opts.jitter ?? 0.07;
  const seed = opts.seed ?? hashString(base);
  const key = `pixel|${base}|${repeat.join(",")}|${size}|${jitter}|${seed}`;

  return texture(
    key,
    size,
    size,
    (ctx) => {
      const rand = mulberry32(seed);

  );
}

/** Two-tone stripes, vertical or horizontal. Used for the hospital gown, wood, walls. */
export function stripeTex(
  a: string,
  b: string,
  opts: { count?: number; horizontal?: boolean; repeat?: [number, number]; seed?: number } = {},
): THREE.CanvasTexture {
  const count = opts.count ?? 4;
  const repeat = opts.repeat ?? [1, 1];
  const key = `stripes|${a}|${b}|${count}|${opts.horizontal ? "h" : "v"}|${repeat.join(",")}|${opts.seed ?? 0}`;

  return texture(
    key,
    8,
    8,
    (ctx) => {
      for (let y = 0; y < 8; y++) {
        for (let x = 0; x < 8; x++) {

          ctx.fillStyle = band % 2 === 0 ? a : b;
          ctx.fillRect(x, y, 1, 1);
        }
      }
    },
    repeat,
  );
}

export type PosterOptions = {
  title: string;
  subtitle?: string;
  lines?: string[];
  bg?: string;
  fg?: string;
  accent?: string;
  /** Draw a colourful 4×3 block grid like the "MY TIMETABLE" chart. */
  grid?: boolean;
  /** 0..1, relative text size. */
  scale?: number;
  border?: boolean;
};

/** A pixelated wall poster / sign. Text is rasterised tiny and upscaled for the Minecraft look. */
export function posterTex(opts: PosterOptions): THREE.CanvasTexture {
  const {
    title,
    subtitle,
    lines = [],
    bg = "#e6dfcc",
    fg = "#1b2028",
    accent = "#c8402f",
    grid = false,
    scale = 1,
    border = true,
  } = opts;
  const key = `poster|${JSON.stringify(opts)}`;

  return texture(key, 96, 128, (ctx) => {
    ctx.fillStyle = bg;
    ctx.fillRect(0, 0, 96, 128);

    if (border) {
      ctx.strokeStyle = shade(bg, -0.35);
      ctx.lineWidth = 4;
      ctx.strokeRect(2, 2, 92, 124);
      ctx.strokeStyle = accent;
      ctx.lineWidth = 2;
      ctx.strokeRect(6, 6, 84, 116);
    }

    ctx.fillStyle = fg;
    ctx.textAlign = "center";
    ctx.textBaseline = "middle";
    const titleSize = Math.max(8, Math.round(13 * scale));
    ctx.font = `bold ${titleSize}px monospace`;
    ctx.fillText(title, 48, 22);

    if (subtitle) {
      ctx.font = `bold ${Math.max(6, Math.round(8 * scale))}px monospace`;
      ctx.fillStyle = accent;
      ctx.fillText(subtitle, 48, 34);
    }

    if (grid) {
      const colors = ["#3b74c4", "#d9a441", "#4a9b5c", "#b8543c", "#7a5aa6", "#3f9aa0"];
      for (let row = 0; row < 3; row++) {
        for (let col = 0; col < 4; col++) {
          ctx.fillStyle = colors[(row * 4 + col + 1) % colors.length];
          ctx.fillRect(10 + col * 20, 42 + row * 20, 18, 18);
          ctx.fillStyle = "rgba(0,0,0,0.25)";
          ctx.fillRect(10 + col * 20, 58 + row * 20, 18, 2);
        }
      }
      ctx.fillStyle = fg;
      ctx.font = `bold 7px monospace`;
      ctx.fillText("WEEK 12", 48, 104);
      return;
    }

    ctx.font = `bold ${Math.max(6, Math.round(9 * scale))}px monospace`;
    lines.forEach((line, i) => {
      ctx.fillStyle = i === 0 ? accent : fg;
      ctx.fillText(line, 48, 46 + i * 12);
    });
  });
}

/** Night sky with a moon, stars and a rooftop silhouette. This is the hero window. */
export function moonWindowTex(): THREE.CanvasTexture {
  const key = "moonwindow";
  return texture(key, 48, 48, (ctx) => {
    const rand = mulberry32(2024);

    // sky gradient
    for (let y = 0; y < 48; y++) {
      const k = y / 47;
      const r = Math.round(10 + (26 - 10) * k);
      const g = Math.round(16 + (38 - 16) * k);
      const b = Math.round(34 + (74 - 34) * k);
      ctx.fillStyle = `rgb(${r},${g},${b})`;
      ctx.fillRect(0, y, 48, 1);
    }

    // stars
    for (let i = 0; i < 70; i++) {
      const x = Math.floor(rand() * 48);
      const y = Math.floor(rand() * 34);
      const bright = rand();
      ctx.fillStyle = bright > 0.92 ? "#ffffff" : `rgba(220,235,255,${0.25 + bright * 0.5})`;
      ctx.fillRect(x, y, 1, 1);
    }

    // moon with craters
    const mx = 31;
    const my = 12;
    const mr = 7;
    for (let y = -mr; y <= mr; y++) {
      for (let x = -mr; x <= mr; x++) {
        if (x * x + y * y > mr * mr) continue;
        const d = Math.sqrt(x * x + y * y) / mr;
        const crater = (x + 2) ** 2 + (y - 1) ** 2 < 7 || (x - 3) ** 2 + (y + 3) ** 2 < 5;
        ctx.fillStyle = crater ? "#b9c6d8" : shade("#f2f6ff", -d * 0.22);
        ctx.fillRect(mx + x, my + y, 1, 1);
      }
    }
    // halo
    for (let y = -mr - 3; y <= mr + 3; y++) {
      for (let x = -mr - 3; x <= mr + 3; x++) {
        const d = Math.sqrt(x * x + y * y);
        if (d > mr && d <= mr + 3) {
          ctx.fillStyle = `rgba(190,215,255,${(1 - (d - mr) / 3) * 0.22})`;
          ctx.fillRect(mx + x, my + y, 1, 1);
        }
      }
    }

    // drifting cloud
    for (let i = 0; i < 3; i++) {
      const cx = 4 + i * 15;
      const cy = 8 + (i % 2) * 6;
      ctx.fillStyle = "rgba(120,150,195,0.32)";
      for (let k = 0; k < 9; k++) ctx.fillRect(cx + k, cy + (k % 3 === 0 ? -1 : 0), 2, 2);
    }

    // rooftop silhouette with a water tower and chimneys
    ctx.fillStyle = "#070c16";
    ctx.fillRect(0, 38, 48, 10);
    ctx.fillRect(3, 34, 8, 4);
    ctx.fillRect(5, 32, 2, 2);
    ctx.fillRect(18, 35, 10, 3);
    ctx.fillRect(20, 30, 3, 5);
    ctx.fillRect(30, 33, 6, 5);
    ctx.fillRect(38, 36, 9, 2);
    // a couple of lit windows far away
    ctx.fillStyle = "#ffcf7a";
    ctx.fillRect(21, 31, 1, 1);
    ctx.fillRect(32, 34, 1, 1);
  });
}

export type CrayonDrawingOptions = {
  /** "shadow" draws the tall black figure; "family" draws a house and people. */
  kind?: "shadow" | "family";
  paper?: string;
  seed?: number;
};

/** A child's crayon drawing on paper. The shadow variant is the story hook. */
export function crayonDrawingTex(options: CrayonDrawingOptions = {}): THREE.CanvasTexture {
  const { kind = "shadow", paper = "#f4eedd", seed = 5 } = options;
  const key = `crayon|${kind}|${paper}|${seed}`;
  return texture(key, 64, 64, (ctx) => {
    const rand = mulberry32(seed * 7919 + 13);

    ctx.fillStyle = paper;
    ctx.fillRect(0, 0, 64, 64);

    // paper grain
    for (let y = 0; y < 64; y++) {
      for (let x = 0; x < 64; x++) {
        if (rand() > 0.86) {
          ctx.fillStyle = shade(paper, -0.06);
          ctx.fillRect(x, y, 1, 1);
        }
      }
    }

    const stroke = (color: string, x: number, y: number, w: number, h: number) => {
      ctx.fillStyle = color;
      ctx.fillRect(x, y, w, h);
      // crayon raggedness: nibble the edges and let the paper show through
      for (let i = 0; i < w * h * 0.2; i++) {
        const rx = x + Math.floor(rand() * w);
        const ry = y + Math.floor(rand() * h);
        if (rand() > 0.45) {
          ctx.fillStyle = paper;
          ctx.fillRect(rx, ry, 1, 1);
        } else {
          ctx.fillStyle = shade(color, (rand() * 2 - 1) * 0.12);
          ctx.fillRect(rx, ry, 1, 1);
        }
      }
    };

    if (kind === "shadow") {
      // sun
      stroke("#e8c33c", 4, 4, 9, 9);
      // grass
      stroke("#5a9b4a", 0, 50, 64, 10);
      // house on the right: walls, roof, door, window
      stroke("#c8503c", 38, 24, 20, 24);
      for (let i = 0; i < 11; i++) {
        ctx.fillStyle = i % 2 === 0 ? "#8a2f26" : "#a83a2e";
        ctx.fillRect(36 + i, 24 - i, 24 - i * 2, 2);
      }
      stroke("#6d4526", 45, 36, 6, 12);
      stroke("#e8c33c", 40, 28, 5, 5);

      // the tall black figure — the thing he keeps drawing
      const blob = (cx: number, cy: number, r: number) => {
        for (let y = -r; y <= r; y++) {
          for (let x = -r; x <= r; x++) {
            if (x * x + y * y > r * r) continue;
            ctx.fillStyle = shade("#12161f", (rand() * 2 - 1) * 0.28);
            ctx.fillRect(cx + x, cy + y, 1, 1);
          }
        }
      };
      blob(16, 10, 7); // head
      stroke("#12161f", 11, 17, 10, 24); // torso
      stroke("#12161f", 4, 19, 8, 3); // left arm
      stroke("#12161f", 22, 19, 8, 3); // right arm
      stroke("#12161f", 11, 40, 4, 10); // left leg
      stroke("#12161f", 17, 40, 4, 10); // right leg
      // long fingers
      for (let i = 0; i < 4; i++) {
        ctx.fillStyle = "#12161f";
        ctx.fillRect(3, 19 + i, 2, 1);
        ctx.fillRect(30, 19 + i, 2, 1);
      }
      // two white eyes — the only bright thing in the drawing
      ctx.fillStyle = "#f7fbff";
      ctx.fillRect(13, 8, 3, 3);
      ctx.fillRect(18, 8, 3, 3);
      // a few crayon scrapes under the figure, like he kept going over it
      for (let i = 0; i < 40; i++) {
        ctx.fillStyle = shade("#12161f", (rand() * 2 - 1) * 0.3);
        ctx.fillRect(9 + Math.floor(rand() * 14), 42 + Math.floor(rand() * 8), 2, 1);
      }
    } else {
      // family drawing: house, sun, three stick people
      stroke("#e8c33c", 4, 4, 8, 8);
      stroke("#5a9b4a", 0, 52, 64, 8);
      stroke("#c8503c", 34, 24, 22, 24);
      stroke("#3f6fa8", 40, 12, 10, 10);
      stroke("#8a5a34", 46, 36, 6, 12);
      const people: Array<[number, string]> = [
        [8, "#d96a3c"],
        [20, "#3f6fa8"],
        [28, "#4a9b5c"],
      ];
      for (const [x, color] of people) {
        stroke(color, x, 22, 4, 4); // head
        stroke(color, x, 26, 4, 12); // body
        stroke(color, x - 4, 28, 4, 2); // arm
        stroke(color, x + 4, 28, 4, 2); // arm
        stroke(color, x, 38, 2, 10); // leg
        stroke(color, x + 2, 38, 2, 10); // leg
      }
    }
  });
}

/** Speckled vinyl composite floor tile, the stuff every hospital corridor uses. */
export function floorTex(base = "#4a5a63", repeat: [number, number] = [1, 1]): THREE.CanvasTexture {
  const key = `floor|${base}|${repeat.join(",")}`;
  return texture(
    key,
    16,
    16,
    (ctx) => {
      const rand = mulberry32(hashString(key));
      for (let y = 0; y < 16; y++) {
        for (let x = 0; x < 16; x++) {
          const speckle = rand();
          let color = shade(base, (rand() * 2 - 1) * 0.04);
          if (speckle > 0.94) color = shade(base, 0.18);
          else if (speckle < 0.06) color = shade(base, -0.15);
          ctx.fillStyle = color;
          ctx.fillRect(x, y, 1, 1);
        }
      }
      ctx.fillStyle = shade(base, -0.2);
      ctx.fillRect(0, 0, 16, 1);
      ctx.fillRect(0, 0, 1, 16);
    },
    repeat,
  );
}

/**
 * A strip of standing wheat, one metre wide: stalks with pale ears, and nothing between them.
 * It is a CUTOUT: put it on a plane with `alphaTest`, the way Minecraft draws its crops.
 */
export function wheatTex(stalk = "#9a8f3e", ear = "#e3cf78", seed = 1): THREE.CanvasTexture {
  const N = 16;
  return texture(`wheat|${stalk}|${ear}|${seed}`, N, N, (ctx) => {
    const rand = mulberry32(seed * 977 + 13);
    ctx.clearRect(0, 0, N, N);
    for (let x = 0; x < N; x++) {
      if (rand() < 0.14) continue; // a gap: you can see through the row
      const h = 10 + Math.floor(rand() * 6);
      const tone = (rand() * 2 - 1) * 0.12;
      for (let y = 0; y < h; y++) {
        const isEar = h - y <= 3;
        ctx.fillStyle = isEar ? shade(ear, tone + (rand() * 2 - 1) * 0.06) : shade(stalk, tone - 0.2 * (1 - y / h));
        ctx.fillRect(x, N - 1 - y, 1, 1);
      }
    }
  });
}

export const BLOCK_COLORS: Record<BlockKind, string> = {
  grass: "#5fa03c",
  dirt: "#7a5536",
  path: "#b79d63",
  cobble: "#8b8b8b",
  mossy: "#8b8b8b",
  stone: "#8e8e8e",
  stoneBrick: "#878787",
  planks: "#b48d52",
  darkPlanks: "#5c3f24",
  log: "#5d4428",
  leaves: "#3f7f2d",
  bricks: "#9c5240",
  wool: "#e9e9e9",
  sand: "#dccf9a",
  hay: "#c9a53a",
  basalt: "#3d3944",
  obsidian: "#1e172b",
  magma: "#2b1c1c",
  lava: "#ff7a14",
};

/** A tileable 16×16 block face. `tint` replaces the block's base colour (dyed wool, autumn leaves). */
export function blockTex(kind: BlockKind, tint?: string): THREE.CanvasTexture {
  const base = tint ?? BLOCK_COLORS[kind];
  const N = 16;
  return texture(`block|${kind}|${base}`, N, N, (ctx) => {
    const rand = mulberry32(hashString(kind) * 31 + 7);
    const put = (x: number, y: number, color: string) => {
      ctx.fillStyle = color;
      ctx.fillRect(((x % N) + N) % N, ((y % N) + N) % N, 1, 1);
    };
    const noise = (amount: number, colour = base) => {
      for (let y = 0; y < N; y++) for (let x = 0; x < N; x++) put(x, y, shade(colour, (rand() * 2 - 1) * amount));
    };
    const speckle = (count: number, amount: number, colour = base) => {
      for (let i = 0; i < count; i++) put(Math.floor(rand() * N), Math.floor(rand() * N), shade(colour, amount));
    };
    /** Rounded stones with dark joints: each pixel belongs to its nearest seed, wrapping at the edges. */
    const stones = (seeds: number, joint: string, fill: (seed: number) => string) => {
      const pts = Array.from({ length: seeds }, () => [rand() * N, rand() * N, rand()] as const);
      const owner = (x: number, y: number) => {
        let best = 0;
        let bestD = 1e9;
        pts.forEach(([px, py], i) => {
          const dx = Math.min(Math.abs(x - px), N - Math.abs(x - px));
          const dy = Math.min(Math.abs(y - py), N - Math.abs(y - py));
          const d = dx * dx + dy * dy * 1.6;
          if (d < bestD) {
            bestD = d;
            best = i;
          }
        });
        return best;
      };
      for (let y = 0; y < N; y++) {
        for (let x = 0; x < N; x++) {
          const o = owner(x, y);
          const edge = owner(x + 1, y) !== o || owner(x, y + 1) !== o;
          put(x, y, edge ? joint : shade(fill(o), (rand() * 2 - 1) * 0.05 + (pts[o][2] - 0.5) * 0.22));
        }
      }
    };

    switch (kind) {
      case "grass":
        noise(0.13);
        speckle(26, 0.22);
        speckle(22, -0.24);
        break;
      case "leaves":
        noise(0.16);
        speckle(40, -0.42);
        speckle(18, 0.25);
        break;
      case "dirt":
        noise(0.1);
        speckle(20, -0.25);
        speckle(10, 0.2);
        break;
      case "path":
        noise(0.08);
        speckle(18, -0.18);
        speckle(10, 0.16);
        break;
      case "sand":
        noise(0.06);
        speckle(14, -0.12);
        break;
      case "wool":
        noise(0.05);
        for (let y = 0; y < N; y += 4) for (let x = 0; x < N; x++) if (rand() > 0.35) put(x, y + (x % 2), shade(base, -0.1));
        break;
      case "stone":
        noise(0.06);
        for (let i = 0; i < 12; i++) {
          const x = Math.floor(rand() * N);
          const y = Math.floor(rand() * N);
          const len = 2 + Math.floor(rand() * 4);
          for (let k = 0; k < len; k++) put(x + k, y, shade(base, -0.16));
        }
        break;
      case "basalt":
        noise(0.1);
        for (let x = 0; x < N; x++) if (rand() > 0.55) for (let y = 0; y < N; y++) if (rand() > 0.3) put(x, y, shade(base, -0.28));
        break;
      case "obsidian":
        noise(0.12);
        speckle(16, 0.3, "#5b3f8c");
        break;
      case "cobble":
        stones(9, shade(base, -0.5), () => base);
        break;
      case "mossy":
        stones(9, shade(base, -0.5), (seed) => (seed % 3 === 0 ? "#5c8a3a" : base));
        speckle(22, 0, "#6a9a40");
        break;
      case "magma":
        stones(8, "#ff8a1e", () => base);
        speckle(10, 0, "#ffd04a");
        break;
      case "stoneBrick":
        for (let y = 0; y < N; y++) {
          for (let x = 0; x < N; x++) {
            const row = Math.floor(y / 8);
            const mortar = y % 8 === 7 || (x + row * 8) % 16 === 15;
            const top = y % 8 === 0;
            put(x, y, mortar ? shade(base, -0.42) : shade(base, (rand() * 2 - 1) * 0.05 + (top ? 0.12 : 0)));
          }
        }
        break;
      case "bricks":
        for (let y = 0; y < N; y++) {
          for (let x = 0; x < N; x++) {
            const row = Math.floor(y / 4);
            const mortar = y % 4 === 3 || (x + (row % 2) * 4) % 8 === 7;
            put(x, y, mortar ? "#c9bcae" : shade(base, (rand() * 2 - 1) * 0.09));
          }
        }
        break;
      case "planks":
      case "darkPlanks": {
        const joints = [3, 11, 7, 14];
        for (let y = 0; y < N; y++) {
          const row = Math.floor(y / 4);
          const tone = (((row * 7) % 5) - 2) * 0.03;
          for (let x = 0; x < N; x++) {
            const seam = y % 4 === 3 || x === joints[row % 4];
            put(x, y, seam ? shade(base, -0.34) : shade(base, tone + (rand() * 2 - 1) * 0.045));
          }
        }
        break;
      }
      case "log":
        for (let x = 0; x < N; x++) {
          const column = (rand() * 2 - 1) * 0.2;
          for (let y = 0; y < N; y++) put(x, y, shade(base, column + (rand() * 2 - 1) * 0.06 - (rand() > 0.9 ? 0.25 : 0)));
        }
        break;
      case "hay":
        for (let y = 0; y < N; y++) for (let x = 0; x < N; x++) put(x, y, shade(base, (y % 3 === 0 ? -0.2 : 0.05) + (rand() * 2 - 1) * 0.08));
        break;
      case "lava":
        for (let y = 0; y < N; y++) {
          for (let x = 0; x < N; x++) {
            const a = (x / N) * Math.PI * 2;
            const b = (y / N) * Math.PI * 2;
            const v = Math.sin(a + Math.sin(b) * 1.3) + Math.sin(b * 2 + Math.cos(a) * 1.1) + (rand() - 0.5) * 0.5;
            put(x, y, v > 1.0 ? "#ffe066" : v > 0.3 ? "#ffab1e" : v > -0.7 ? "#f5700f" : "#c93c08");
          }
        }
        break;
    }
  });
}

import type React from "react";

/**
 * A SHOT is a single, motivated camera move inside a scene.
 * Every shot must fill in `note` with the storytelling reason for the move.
 */
export type Shot = {
  /** Seconds into the scene when this shot begins. 0 for the first shot. */
  at: number;
  /** Duration of this shot in seconds. */
  dur: number;

  /** Camera start position (world units, 1 unit = 1 metre). */
  from: Vec3;
  /** Camera end position. Omit for a locked-off shot. */
  to?: Vec3;
  /**
   * Optional multi-point flight path. Overrides `to`.
   * The camera travels smoothly through every point. Use this for fly-throughs
   * between rooms and reveals.
   */
  path?: Vec3[];

  /** What the camera is looking at on the first frame. */
  target: Vec3;
  /** What it is looking at on the last frame. Omit to hold the same subject. */
  targetTo?: Vec3;
  /** Multi-point look path, for panning from one subject to another during a move. */
  targetPath?: Vec3[];

  /** Vertical field of view, degrees. Default 38. Ignored when `focalLength` is set. */
  fov?: number;
  fovTo?: number;

  /**
   * Lens focal length in millimetres (full-frame 24mm sensor height).
   * Overrides `fov`/`fovTo` when present. 24 = wide, 35 = natural,
   * 50 = portrait compression, 85 = threat. Matches docs/CAMERA-BIBLE.md.
   */
  focalLength?: number;
  /** End focal length for a slow zoom. Defaults to `focalLength`. */
  focalLengthTo?: number;

  /** Easing for the move. Default "inOutCubic". Use "linear" for constant tracking. */
  ease?: EaseName;

  /** Sideways bow in metres, useful for orbiting arcs. Ignored when `path` is set. */
  arc?: number;
  /** Handheld instability, in metres. Keep 0.005–0.03. Never shake everything. */
  shake?: number;
  /**
   * Low-frequency handheld drift in metres. Much slower and smaller than `shake`;
   * this is the breathing of the operator, not the impact of a footstep.
   */
  handheld?: number;
  /** Timed impact impulses: a short burst of shake at a specific second. */
  impacts?: Array<{ at: number; amp: number; dur?: number }>;
  /** Camera roll in radians. */
  roll?: number;
  /** End roll in radians. The roll eases from `roll` to `rollTo` (a rotating top-down shot). */
  rollTo?: number;
  /** Raise/lower the look point, for headroom in the 9:16 frame. */
  aim?: number;

  /** Lighting preset for this shot only. Falls back to the film's `look`. */
  look?: LookPreset;
  /** World zone this shot plays in. `<Zone name>` groups in the world hide when another zone is on. */
  zone?: string;
  /** Narration cue this shot is cut to. Set by `storyScene`; see docs in Topics/. */
  cue?: string;

  /** Deliberately lock the lens (e.g. the family photograph). Explain the hold in `note`. */
  locked?: true;
  /** The storytelling purpose of this shot. REQUIRED for reviewability. */
  note: string;
};
